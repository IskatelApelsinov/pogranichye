# 2 — Толстый клиент (Unity)

Готовая к игре 3D-витрина поверх сервера. Движок — Unity (C#). Вся логика мира на сервере;
клиент рисует состояние и шлёт намерения по websocket/JSON (engine-agnostic протокол).

- `game/`      (2.1) — сам клиент, сборка под запуск (.exe и др.).
- `extras/`    (2.2) — доп. ПО, инструкции, ссылки (ассеты, шрифты, зависимости).
- `installer/` (2.3) — установщик толстого клиента.

Пока пусто: встаёт после сетевого слоя сервера (шаг 2 дорожной карты).
