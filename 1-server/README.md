# 1 — Сервер (Go): мозг и память живого мира

Мир живёт здесь. Клиенты (толстый Unity, тонкий web) — лишь окна, общаются по websocket/JSON.

- `core/` (1.1) — субстрат: сущности, компоненты-свойства, мир, часы, прокрутка систем. Ядро без правил.
- `sim/`  (1.1) — правила жизни: нужды, старение/смертность/рождения, взросление, разум-в-деле.
- `mind/` (1.4) — «мысли» НПС: чистый выбор цели по нуждам/тягам (ничего не мутирует).
- `memory/`(1.2) — память БЕЗ ПОТЕРЬ: снимок каждой сущности+свойства + состояние костей.
- `dice/` (1.3) — детерминированные «кости» (splitmix64, именованные потоки).
- `worldmut/` (1.5) — изменение физического мира (разрушение/постройка) — задел на будущее.
- `thin-client/` (1.6) — тонкий клиент (перенос поверх ядра).
- `cmd/pogserver/` — вход: сейчас демо-прогон, дальше websocket-сервер.

Запуск: `go test ./...` и `go run ./cmd/pogserver -days 5910`.
Как добавить модуль, не трогая ядро — см. `3-dev/docs/СКЕЛЕТ-ЖИВОГО-МИРА.md`, раздел 3.
