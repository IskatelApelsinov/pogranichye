# Приграничье — толстый клиент (3D)

Полноценный толстый клиент, начатый сразу **в 3D** с видом сверху
(ортографическая камера, лёгкий наклон — «2.5D-ощущение»). Это оболочка
поверх уже готового сервера: вся логика мира — на сервере, клиент только
рисует присланное состояние 3D-мешами и шлёт **намерения** (тот же
WebSocket-протокол, что у браузерного тонкого клиента).

## Запуск
1. Подними сервер в dev-режиме (чтобы работал гостевой вход):
   ```
   GAME_ENV=dev python3 netserver.py
   ```
   (или в Docker — но для гостевого входа нужен `GAME_ENV=dev`).
2. Godot **4.3+** → *Import* → выбрать папку `godot3d-client/`.
3. Если сервер не на этой же машине — открой `Main.tscn`, выдели узел `Main`
   и поправь в инспекторе `host`/`port` (по умолчанию `127.0.0.1:8090`).
4. F5 (запустить).

## Что уже есть
- Ортокамера, вид сверху, наклон; солнце и окружение меняются день/ночь.
- 3D-деревня: пол-плитки, дома с крышами, таверна, деревья по краям.
  Зимой/в холод плитки и кроны светлеют.
- Токены жителей (капсулы, цвет по ремеслу) и игрок (золотой) плавно едут
  к целям по времени суток: день — по делам, вечер — в таверну, ночь — по домам.
  Имена — billboard-подписи над головой.
- Панель действий: дрова, рыба, охота, выпить, очко, спать, в путь, сохранить.
- Статус-строка (деревня, день/час, сезон/погода, ★/монеты/тепло/усталость/голод).
- Лог ответов сервера; автобой при встрече зверя (как в прототипе).

## Протокол (как подключается)
1. `POST /auth/guest` по HTTP → из ответа берётся cookie `sid` и `token`.
2. WebSocket на `/ws` с заголовком `Cookie: sid=…` (плюс `?sid=token` как запас —
   сервер принимает токен и из query).
3. Приём: первый пакет — полный снимок (`state`), дальше — только дельты (`delta`).
   Отправка: `{op, rid, …}` — намерения (`do`, `hunt`, `drink`, `card`, `travel`, `sleep`, `save` …).

## Управление
- **Клик по жителю** — выбрать (подсветка + подпись кто это); клик по таверне —
  подсказка о действиях.
- **🎒 Вещи** — панель инвентаря и экипировки (паперdoll): надеть/снять по слотам
  (голова/тело/верх/ноги/оружие/оберег), на склад, продать; видно тепло и монеты.
- **Занятия через мини-игру**: «Дрова/Рыба/Травы» открывают полоску тайминга —
  останови бегунок (пробел или «Стоп») ближе к центру, точность = качество.
- Охота/выпить/очко/дурак/спать/в путь/сохранить — сразу.

## Дальше (следующие шаги толстого клиента)

- Экраны торговли и квестов; больше типов мини-игр (удержание, прицел).
