# ADR 0003 — Модель мира: демо-территория, внешний мир и роль travel

Дата: 2026-11-09. Статус: принято (канон владельца, 0045/0046). Связано: #39, worldgen, expansion.

## Контекст
Владелец уточнил (0045→0046) канон географии:
- **Демо-территория** — ограниченная стартовая зона из нескольких деревень (Починок, Берёзовка,
  Залесье, Крутой Яр…). Между ними перемещение ФИЗИЧЕСКОЕ по дорогам; телепортов деревня-деревня нет.
  Внешнюю границу зоны образует дальний горный барьер; выход в открытый мир — особый переход/gateway.
- **Открытый мир** — большая единая география из регионов; перемещение между поселениями/регионами
  физическое (дороги, мосты, перевалы, броды). Регионы — части одного мира, не отдельные карты.
- `op:"travel"` НЕ является обычным способом путешествия в толстом клиенте.

## Решение
1. **Семантика `op:"travel"`:** оставляем ТОЛЬКО как (а) thin-client/менеджмент-абстракцию быстрого
   перехода и (б) будущий демо→open-world gateway/debug. В толстом клиенте обычное перемещение
   деревня-деревня travel'ом не делаем. Поле `me.world[].outer` помечает поселения открытого мира
   (за горами), доступные как «дальше по карте», а не как повседневная телепортация.
2. **Регион ≠ недостижимость:** убрана глобальная `homeRegion`; `outer` вычисляется по флагу
   `RegionC.Outer` конкретного региона (без скрытого mutable-состояния). Внешние регионы помечены
   `Outer:true` при генерации.
3. **Локальная геометрия v2 (300×300) — подучасток демо-территории** одного поселения; внутри неё
   навигация идёт по waypoint-графу дорог (ADR-уровень реализован, #39). Глобальные координаты мира и
   бесшовные переходы между регионами — отдельная веха (ниже), контракт к ней готовим, но не внедряем.
4. **Приоритет демо (#80):** сперва играбельная петля в стартовой деревне (знакомство → работа →
   корчма), затем связывание демо-деревень дорогами и физический переход. Контракт кадра остаётся
   `v:1`, GeometryVersion=2 не меняется.

## Что НЕ делаем сейчас (вехи, по согласованию)
- Глобальные world-координаты + региональный стриминг + бесшовные границы регионов.
- Физические межпоселенческие дороги в толстом клиенте и переход демо→open-world с переносом
  персонажа/инвентаря/времени и поведением при reconnect.
- A* по глобальному дорожному графу между поселениями.

## Тесты (текущие)
Внутренний waypoint-граф: достижимость всех POI от колодца, рёбра не пересекают здания/реку вне моста.
Travel помечает `visited`; `outer` вычисляется без глобала (two-world независимость не требуется, но
скрытое состояние убрано).
