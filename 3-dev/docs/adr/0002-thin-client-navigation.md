# ADR 0002 — Тонкий клиент: кликер-навигация, толстый клиент: ходьба

Дата: 2026-11-06. Статус: принято (решение владельца, 0040). Связано: ПРОТОКОЛ §3.6.

## Контекст
Тонкий web/mobile клиент и толстый Unity делят один серверный мир, но у них РАЗНЫЙ UX. Владелец
уточнил (0040): тонкий клиент — браузерная/мобильная игра по кликам/тапам (формат фермы/менеджмента),
а не уменьшенная копия Unity. Он НЕ должен симулировать свободную ходьбу аватара ради паритета.

## Решение
- **Тонкий клиент:** навигация дискретная — тап по локации. Новое серверное намерение `op:"goto"
  {location}` ставит тело игрока в точку локации (серверно-авторитетно). Действия по близости работают,
  т.к. тело уже там. Мини-игры — компактные экраны, запускаемые из локации (рыбалка, рубка — есть;
  ремесло/хозяйство — далее). WASD/джойстик в тонкий клиент НЕ добавляем.
- **Толстый клиент (Unity):** непрерывная ходьба `op:"move"` + сцена/камера/физика. Прыжок —
  клиентский визуал; серверная позиция остаётся плоской и авторитетной, пока не согласована
  вертикальная физика отдельным контрактом (клиентскую высоту как серверную позицию не слать).
- Оба клиента двигают ОДНО тело; выбор способа навигации — за клиентом. Контракт общий, аддитивный.

## Последствия
- `goto` реализован (v1.6). Тонкий клиент переведён в тап-формат с мини-играми, ходьба убрана.
- Новые локационные действия (помощь в работе, торговля) добавляются как серверные actions по
  согласованию (контракт + ADR), мини-игры клиент рисует отдельными экранами.
