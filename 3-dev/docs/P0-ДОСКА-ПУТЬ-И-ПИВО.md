# P0-доска: путь + пиво с другом

Дата: 2026-11-14 (Grok)  
Fantasy владельца: романтика долгой дороги; выпить пива в корчме; **с другом** (MP).  
Лошадь — не P0. Atmosphere: Frieren / Kenshi / Tarkov / Outward — компас, не бэклог.

## Критерии «готово» для владельца

1. **Путь:** выйти пешком за околицу → мир растёт / горизонт не вечная пустая плоскость; можно идти к другому селу.  
2. **Корчма:** днём дойти до стойки → купить/выпить **или** чокнуться с вторым игроком; виден хотя бы корчмарь у стойки.  
3. Один мир, два клиента, server-authoritative.
