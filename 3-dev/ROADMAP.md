- [x] Флаки `TestVerticalSliceTalkWorkBeer` ("корчмаря сейчас нет за стойкой") — найден и исправлен
      (2026-11-20, по статусу Grok 0311/0312). Причина: тест идёт по настенным часам (тик 400мс/час)
      через talk+work+errand ПЕРЕД покупкой пива, а `bartenderServing` открыт только в игровые часы
      `[10,22)` (comms 0242) — под нагрузкой параллельного сюита реального времени на эти шаги могло
      уйти достаточно, чтобы игровой час утёк за полночь ровно к моменту покупки. Это не баг контракта
      и не баг расписания (оба уже честно покрыты `sim/tavern_test.go` с явным управлением часом) — это
      нестабильность самого E2E-сценария. Фикс: прямо перед шагом покупки пива тест сам пинит
      `s.runner.Clock.TotalHours` на полдень того же (или следующего, если полдень уже прошёл) игрового
      дня — монотонность часов не нарушается, остальные шаги сценария не трогаются. 3 изолированных
      прогона `-run TestVerticalSliceTalkWorkBeer -count=3` зелёные (40с каждый), плюс 2 полных
      `go test ./...` подряд зелёные. Никаких изменений контракта/wire — чистый тестовый фикс.
      PR `fix/flaky-tavern-beer-hour-pin-20261120` (не мерджить без Kate).

## Правила автономного запуска
1. Свежие comms/PR от ChatGPT — читать и выполнять в первую очередь (или обосновать отказ в comms).
2. Один связный срез за запуск; контракт менять только аддитивно (кадр `v:1`); при новом поле —
   fixture + контракт-док + тест.
3. Проверка: `go build ./... && go vet ./... && go test ./...` + один живой WS-дым; чистый клон не
   обязателен ежедневно (экономия токенов), но перед мерджем тесты обязаны быть зелёными.
4. В main НЕ мерджить: работа через ветки и PR, мердж — только вместе с Kate (её правило от
   2026-11-10). Коммит с атрибуцией. Отметить пункт `[x]` в ветке.
5. В конце недели — совместная проверка с Kate и ChatGPT.
