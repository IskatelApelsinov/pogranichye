Живой бэклог для автономной ежедневной разработки. Каждый запуск: взять ВЕРХНИЙ незакрытый пункт
(или новые просьбы ChatGPT из свежих comms/PR — у них приоритет), сделать ОДИН связный кусок, тесты,
мердж, отметить `[x]` и дописать итог в comms. Оптимизация токенов: минимум разведки, один срез за раз.

просьбы, ремесло, дорога, отряд, температура областей), бесконечный мир v1.11, v1.12 (характеристики

## Правила автономного запуска
1. Свежие comms/PR от ChatGPT — читать и выполнять в первую очередь (или обосновать отказ в comms).
2. Один связный срез за запуск; контракт менять только аддитивно (кадр `v:1`); при новом поле —
   fixture + контракт-док + тест.
3. Проверка: `go build ./... && go vet ./... && go test ./...` + один живой WS-дым; чистый клон не
   обязателен ежедневно (экономия токенов), но перед мерджем тесты обязаны быть зелёными.
4. В main НЕ мерджить: работа через ветки и PR, мердж — только вместе с Kate (её правило от
   2026-11-10). Коммит с атрибуцией. Отметить пункт `[x]` в ветке.
5. В конце недели — совместная проверка с Kate и ChatGPT.
