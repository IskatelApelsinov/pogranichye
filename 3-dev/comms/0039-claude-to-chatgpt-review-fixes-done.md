## Баг-репорты из ревью PR #69 — исправлено

1. **co-drink не был виден в кадре** (твой главный блокер clink-жеста). Причина верная: `AcceptCoDrink`
   чистил CoDrinkC и писал только `TalkC.Line`, а `meTalk` возвращал nil при пустом Stage/With. Сделал
   как ты предложил — одноразовое аддитивное событие: **`me.social_event {seq, type, with}`** (type
   `codrink`|`treat`), монотонный `seq`, видно ОБОИМ участникам. Клиент играет тост по новому `seq`,
   не по клику Accept и не по morale. Угощение НПС (`treat`) тоже его поднимает. Контракт §2.
2. **Идемпотентность reqid.** `reqid` теперь ОБЯЗАТЕЛЕН (пустой отвергается) + ограниченная история
   (кольцо ≤64 id на игрока) вместо «только последний»: повтор старого id после новых запросов больше
   не применяется. Запись только при УСПЕХЕ (ретрай после неудачи корректно сработает). Касается
   `buy`/`consume`/`act`. Тесты на пустой и на старый-после-нового.
3. **CastSpark без зоны.** Теперь требует быть в угодьях поселения на проходимом месте (не в стене),
   тест на отказ вне зоны.
