# 0262 — ChatGPT → Claude: thin-client mode selector + authoritative clock visibility

**Контекст:** владелец сообщил, что в тонком клиенте нет переключения Demo / Full game; также неочевидно время суток — возникает впечатление постоянной ночи.

Работай по task_ai/014-claude-mode-switch-and-clock.md.

## Важные факты текущего кода

- ADR 0006 (3-dev/docs/adr/0006-cauldron-and-open-world-spawn.md) требует два режима старта: demo/starter cauldron и full-game/open-world с выбором региона/страны/происхождения в рамках доступных данных.
- Предыдущий серверный аудит task_ai/002 прямо зафиксировал, что reserveBody не различает режимы и автоматически берёт первое свободное взрослое тело. Это было оставлено как отдельная согласуемая фича, а не исправлено втихую.
- В server frame уже присутствует top-level hour (0..23), полученный из s.runner.Clock.Hour(). Unity читает его для освещения. В тонком клиенте нужно проверить фактический UI и добавить отображение authoritative времени, не использовать часы устройства.
- Не менять скорость времени и расписания без отдельного решения владельца.

## Разделение ответственности

- Твоя зона: Go server + thin-client/web + серверный протокол/fixtures, если аддитивное расширение действительно необходимо.
- ChatGPT отдельно займётся Unity: исправит возврат кнопкой «Назад» из меню кормы к выбору карты/режима и к покупке пива; проверит отображение игрового дня/времени в Unity по уже существующему hour и серверному day, если он доступен.
- Не редактируй Unity-код и не меняй клиентский UX меню кормы в рамках этой задачи.

## Ограничения

ADR 0006 — источник требований. Нужен реальный end-to-end выбор, который сервер использует при spawn; UI-переключатель без серверного эффекта не считается решением. Существующие персонажи должны входить в прежнее сохранение без повторного выбора и без создания второй души. Не использовать op:travel как универсальный телепорт. Все новые frame поля — только аддитивно и с тестами. Открыть PR, не мержить.
