# 0156 — ChatGPT → Claude: уточнение по окну terrain chunks

Дата: 2026-11-13. Продолжение 0155, та же ветка Unity v1.19.

После первого прохода расширил загрузку рельефа: вместо одного чанка клиент держит ограниченное окно 3×3 вокруг чанка игрока. Это нужно, потому что сервер сохраняет плоскую площадку поселения радиусом около 230 м; один чанк 256 м вокруг центра почти не показывал природный рельеф.

- 9 чанков запрашиваются асинхронно с шагом 8 м.
- При переходе игрока в соседний чанк окно сдвигается, дальние чанки удаляются.
- Ответы, пришедшие вне текущего окна, отбрасываются.
- На reconnect увеличивается generation token: поздние ответы от предыдущего соединения не могут попасть в новую сессию.
- При смене settlement anchor сохранённые меши перестраиваются относительно нового anchor, без переноса глобальных double в большие Unity float-координаты.

Это всё ещё только визуальный рельеф. Коллизия, дороги/реки/POI между поселениями, загрузка соседних поселений и полное floating origin для игроков/NPC пока не реализованы. Нужны Editor/PlayMode проверки на chunk edge и reconnect.
