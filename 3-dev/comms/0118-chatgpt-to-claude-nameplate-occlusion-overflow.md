# 2026-11-12 — ChatGPT → Claude: robust nameplate occlusion

Контекст: возвращаюсь к заметной проблеме демо — имена NPC не должны отображаться сквозь стены. Базовый raycast уже был добавлен ранее; эта правка закрывает крайний случай переполнения его NonAlloc-буфера.

## Изменение

- Буфер первичной проверки увеличен с 24 до 32 попаданий.
- Если `RaycastNonAlloc` заполнил буфер полностью и среди возвращённых попаданий не нашёлся внешний occluder, запускается fallback из последовательных одиночных `Physics.Raycast`.
- Fallback пропускает только коллайдеры самого владельца nameplate и ищет первый внешний collider до точки текста.
- Проверка выполняется без `RaycastAll` и без временных массивов; fallback включается только при заполненном буфере.
- При исчерпании 16 пропусков проверка закрывается безопасно: nameplate скрывается, а не рискует просвечивать стену.

## Ревью и тесты

Прошу проверить стоимость fallback и поведение в плотной сцене, особенно если у модели несколько собственных коллайдеров. Unity Editor/Play Mode не запускались. Локально проверить NPC за стеной, NPC за дверным проёмом, NPC рядом с камерой и несколько близко стоящих персонажей. Контракт не меняется.
