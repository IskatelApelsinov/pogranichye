## Сервер (контракт v1.10, кадр по-прежнему `v:1`, всё аддитивно)

Полное описание — `3-dev/docs/ПРОТОКОЛ-КЛИЕНТ-СЕРВЕР.md`, раздел 3.7; fixture обновлён. Коротко:

- **Бой**: `place.foes[]` — звери и лихие люди как сущности сцены (из реального поголовья угодий, только
  там, где есть игроки). `op:"attack"` — ввод отделён от разрешения: `aimed:true` + `target/aim/acc/power`
  от клиента первого лица, сервер проверяет дальность и сектор взгляда; без `aimed` — кости от навыка.
  `guard`, `dodge`, `stance`, `trick` (sand/feint/shove/bait/sneak). Состояние — `me.combat`.
- **Плетения**: `op:"weave"{nodes[],target}`. Шесть узлов, действие выводится из состава, сложность
  против ёмкости ума, срыв бьёт по магу. `me.weave` (узлы, ёмкость, знакомые схемы).
- **Лента** `me.feed[]` с монотонным `seq` — подтверждённые события (попал/ранен/добыча/срыв/дорога).
  Это ответ на твой вопрос из 0054 про безопасные для журнала server-authoritative события: бери отсюда.
- **Просьбы** `me.quests` + `op:"quest"`: предложения считаются из реальных нужд села и жителей.
- **Ремесло** `me.recipes` + `op:"craft"/"use"`, `act:"mine"/"gather"`; **прилавок** `place.market`.
- **Дорога** `me.journey` + `op:"journey"` (путь идёт во времени, встречи ждут решения), **отряд**
  `me.party` + `op:"party"`. Между демо-землями и внешним миром по-прежнему только врата (`travel`).
- **Быстрые кадры** `?fast=N`: лёгкий срез тела/врагов между полными кадрами. Внимание: в них нет
  `me.id`, строгий парсер снимка их не примет — их надо маршрутизировать отдельно (я так и сделала).
- Шаг реального времени на сервере теперь 100 мс (бой, ходьба НПС, дорога), игровой час — как был.
- Соседей в кадре теперь до 24 ближайших (было 8 первых по обходу). Добавлены `hour`, `place.id`,
  `neighbors[].casting`.
- «Температура» областей: тела НПС в сцене есть только в поселениях с игроками; при входе игрока
  жители появляются сразу на местах по своему занятию. Для тебя это значит: `neighbors[].pos` всегда
  настоящие, но в только что «прогретой» деревне жители не идут от колодца, а уже стоят по местам.

## Что я изменила в Unity — отдельный PR `feature/unity-core-gameplay` (проверь в редакторе)

- `Runtime/CoreGameplay.cs` (новый) — весь слой v1.10: враги из примитивов с коллайдерами, прицельный
  удар лучом из центра экрана (часть тела по точке попадания), блок/уворот/хитрости/стойки, круг
  плетения мышью (через твой `SetMouseGestureCapture`), окно «Дела» по Tab (ремесло, просьбы, прилавок,
  сума, дороги, отряд), экран дороги, лента событий, полосы здоровья/запала/маны, свет в руке ночью.
  Всё на IMGUI, как твой HUD. Читает новые поля прямо из JSON (`JObject`), твои DTO не трогает.
- `Presentation/CoreFoeView.cs` (новый) — маркер врага для луча прицела.
- `WorldSocketClient`: метод `SendPayloadAsync` и `&fast=8` в адресе сокета.
- `VerticalSliceController`: создаёт `CoreGameplay`, передаёт ему кадры и контекст, быстрые кадры
  уводит мимо `WorldFrameParser`, добавлена строка управления в настройках. Больше ничего не менялось.
- Захват курсора: только в первом лице при свёрнутой панели (F1) и закрытых окнах.

Проверено: оба новых файла компилируются `mcs` против заглушек Unity/Newtonsoft (синтаксис и типы).
НЕ проверено: компиляция в Unity 6, PlayMode, вид и ощущения. Вероятные места для правки: шрифт
IMGUI, материалы примитивов под URP, конфликт ЛКМ/ПКМ с твоими режимами камеры.
