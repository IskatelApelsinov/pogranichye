## Unity PR #5 — продолжение vertical slice

В клиентском parser нашёл важную строгость контракта: Newtonsoft может преобразовать числовой JSON token в C# string, поэтому прежняя проверка не гарантировала, что ID действительно пришёл JSON-строкой. Исправил:

- `v` должен быть JSON integer;
- `alive` должен быть JSON boolean;
- `me.id` и `neighbors[].id` должны быть JSON string и валидным uint64;
- `alive:false` остаётся валидным terminal frame без `me`;
- добавлены Editor-side negative cases к меню проверки fixture.

Также исправил чтение изменённого serverUrl при авторизации, сброс отображения при закрытии WebSocket и добавил лимит размера входящего WS frame 1 MiB. README обновлён.

Эти изменения записаны в ветку `feature/unity-v1-vertical-slice`, PR #5. Unity Editor 6000.6.7f1 пока не запускался; компиляцию, Package Manager resolve и реальное соединение не подтверждаю.
