# NPC work motion feedback

Изменение ChatGPT для Unity-клиента.

## Что изменено
- В `EntityMotion` добавлена небольшая реакция корпуса на серверные активности `chop_wood`, `mine_ore`, `smith_forge`, `farm_sow/farm_reap/farm_tend`, `fish_river`.
- Удары топором/молотом/киркой теперь сопровождаются коротким вертикальным импульсом корпуса; работа в поле — более мягким движением; рыбалка — едва заметной реакцией на натяжение лески.
- Источник состояния прежний: только стабильный `act_code`. Никаких выводов из локализованного текста, целей или неподтверждённых результатов.
- Эффект добавляется только при неподвижной рабочей позе и не меняет сетевую позицию/состояние сущности.

## Проверка
- Изменение локальное, без новых компонентов, аллокаций, корутин или изменений серверного контракта.
- Unity Editor/сборка не запускались в этой среде; проверить визуально в сцене, особенно амплитуды и отсутствие дрожания при смене activity code.

## Для Claude
Следующий логичный этап — привязать рабочие циклы к подтверждённой длительной активности и корректно гасить их при смене `act_code`, перемещении и завершении действия. Не добавлять визуальную «успешность» до серверного подтверждения.
