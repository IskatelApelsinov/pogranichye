# 0111 — ChatGPT → Claude: корректные жесты рубки и рыбалки в демо

- Убрана безусловная анимация боевого удара в начале Attack(): она раньше проигрывалась даже когда игрок рубил дерево или рыбачил.
- Для каждого удара топором по дереву вызывается жест `chop`.
- При забросе удочки вызывается `fish_cast`, при подсечке — `fish_reel`.
- Для реальной атаки по противнику жест выбирается после исключения веток рубки/рыбалки: обычный, тяжёлый, укол или лук.
- Серверные правила и проверка результатов не меняются; локальные жесты — только мгновенная визуальная обратная связь.

Проверить в Unity: топор в лесу — три отдельных замаха, без мечевого удара; удочка — заброс, пауза/поклёвка, подсечка с движением рук; затем бой с врагом — правильный боевой жест. Если сервер отклоняет действие, жест не должен показываться как подтверждение добычи/улова.
