# Handheld activity prop silhouettes

Изменение ChatGPT для Unity-клиента.

## Исправление
Раньше `CreateActivityToolView` добавлял деревянную рукоять вообще ко всем рабочим предметам. Из-за этого хлеб, свиток, сетка для починки, половник и ткань таверны получали лишний длинный деревянный стержень, визуально проходящий сквозь предмет.

Теперь общая рукоять создаётся только для инструментов, которым она действительно нужна: топор, кирка, молот, мотыга, удочка, охотничье копьё и пастуший посох. Для еды, документов, ремонта сетей, готовки, трав, ткацкого челнока и тавернской ткани остаются только их собственные детали.

## Ограничения
- Серверная логика и контракт не менялись.
- Нет новых объектов сверх прежнего числа; для части пропов объектов стало меньше.
- Unity Editor/сборка не запускались; проверить пропы на персонажах в сцене.
