## 2. Что можно показывать в журнале без нового wire — РЕАЛИЗОВАНО: `me.journal`
Раньше в кадре не было персональной летописи: мировая `chronicle` (войны/непогода/магия) живёт на
сервере, но в per-player кадр НЕ отдаётся и к игроку прямого отношения не имеет. Поэтому сделал
аддитивное поле **`me.journal`** — личные server-authoritative вехи:

```json
"journal": [
  { "seq": 1, "day": 40, "kind": "met",    "text": "Познакомился с жителем деревни." },
  { "seq": 2, "day": 41, "kind": "worked", "text": "Впервые поработал своими руками." },
  { "seq": 3, "day": 42, "kind": "drank",  "text": "Выпил кружку пива в корчме." }
]
```

- Записи появляются ТОЛЬКО по факту реального состояния (знакомство → `Acquaint`, труд → навык>0,
  пиво → `Player.DrankBeer`), не по клику и не оптимистично. Это те же истины, что в `me.task`.
- Монотонный `seq` (растёт строго вверх), каждый род (`kind`) пишется ровно один раз — идемпотентно,
  пересчёт кадра дублей не плодит. Набор `kind` конечен и пополняется аддитивно.
- Легаси-клиент поле игнорирует; кадр остаётся `"v":1`. Fixture, контракт-док (v1.9) и тест обновлены.

Вкладке «Журнал» из PR #181 теперь есть что показывать из серверной истины: рисуй записи по
возрастанию `seq`, дорисовывай новые. Мировую летопись (если захочешь ленту событий деревни) можно
отдать отдельным аддитивным полем позже — скажи, если нужно, тогда согласуем форму.

## 3. Карта POI / activity-codes / серверных препятствий (текущая геометрия v2, 300×300)

**Server-side препятствия (непроходимы, `Blocked`):** все здания — сплошные прямоугольники, внутрь
НЕ зайти ни НПС, ни игроку:
- Корчма `tavern` [-40..-26, 14..26], Кузница `smithy` [22..36, 16..28], Амбар `granary` [-10..6, 30..42],
  Изба старосты `house` [26..40, -30..-18], Избы `house` [-40..-28,-30..-20], [-14..-2,-34..-24],
  [6..18,-36..-26], Лавка `market` [-6..8, 6..16].
- Река-полоса Y∈[-90,-78] непроходима, КРОМЕ моста X∈[-6,6]. Край мира [-150,150]².

**Доступные точки (POI — у входов/на улице, всегда проходимы), к ним и ходят НПС:**
`tavern(-33,12) smithy(29,14) granary(-2,28) market(1,4) well(0,-4) hearth(33,-32) garden(70,-20)
river(0,-74) woods(-95,10) mine(90,40)`. То есть сейчас «зайти в здание» = встать у его двери-POI;
интерьеры серверу неизвестны.

**Навграф (#39):** 19 узлов по дорогам (well/market/junctions/gates/мост/...), через реку — только
мостовая цепочка `fishing-bank → bridge-north → bridge-center → bridge-south → south-road`. НПС идут
POI→POI по узлам; финальный рывок к точке. Узлы — в `sim/navgraph.go`.

**Activity codes (`act_code`, стабильные, для анимаций):** полный актуальный список — в контракт-доке
(§ v1.2), пополняется аддитивно: `meal, sleep, rest_idle, drink_tavern, visit_neighbors, seek_home,
travel, wander, farm_*, fish_river, fisher_mend, hunt_wild, hunter_empty, cook_hearth, brew_remedy,
forage_herbs, smith_forge, smith_cold, weave, weaver_wait, mine_ore, mine_spent, chop_wood, herd_barn,
herd_graze, keep_tavern, study_mana, work`. **Важно (ответ на твою «следующую работу»):** НПС НЕ
занимаются работой внутри зданий — все рабочие точки (`woods/river/garden/mine/well/market` и двери
`smithy/granary/tavern/hearth`) снаружи. Не рисуй NPC «работающим» в месте, которое сервер считает
непроходимым (внутри прямоугольников выше) — там сервер их никогда не ставит.
