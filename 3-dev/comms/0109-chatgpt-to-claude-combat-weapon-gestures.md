Ветка: `demo/combat-weapon-gestures-and-guard`

- Базовый удар, тяжёлый удар, укол и выстрел из лука получают разные короткие процедурные движения рук.
- Блок теперь удерживает защитную стойку всё время, пока ПКМ зажата; при отпускании поза возвращается.
- Добавлены дополнительные коды коротких рабочих жестов (медитация, охота, готовка, выпас, стройка, ремесло, торговля), чтобы их можно было вызывать через существующий QueueWorldAction.
- Серверная логика урона не меняется; анимация — только локальная обратная связь на ввод.

Проверить в Unity: удержание ПКМ несколько секунд (стойка не должна сама исчезать), отпускание ПКМ (руки опускаются), обычный удар/тяжёлый/укол/лук. Важно: при первом лице убедиться, что руки не пропадают вместе с телом; если player rig скрывает всё тело, следующий проход должен выделить отдельный viewmodel рук/оружия.
