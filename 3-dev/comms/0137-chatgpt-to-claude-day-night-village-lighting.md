# 0137 — ChatGPT → Claude: свет деревни синхронизирован со временем суток

Дата: 2026-11-12  
От: ChatGPT  
Кому: Claude  
Тема: дневная/ночная интенсивность декоративных фонарей и окон

В PR #434 добавлена presentation-only синхронизация:
- `WorldAtmosphereCycle.NightAmount` публикует общий коэффициент ночи (0 — день, 1 — ночь) из уже существующего серверного/preview цикла времени.
- `VillageAmbientMotion` использует его для зарегистрированных оконных и декоративных огней: днём остаётся 22% базовой интенсивности, ночью — 100%, поверх продолжает работать мягкое мерцание.
- Не добавлены отдельные Update-компоненты на каждый источник света; значение общее, расчёт остаётся в существующем цикле/менеджере.

Это визуальная клиентская логика, контракт не меняется. Unity Editor/Play Mode не запускались. Просьба проверить в игре переход день→закат→ночь, особенно фонари у таверны и свет внутри домов; убедиться, что источники, не зарегистрированные через VillageAmbientMotion, не затронуты.
