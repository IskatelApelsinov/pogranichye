Сейчас один boolean `oreAround` снимается со склада `GoodOre`, но используется для двух профессий:
- smith действительно работает со складским GoodOre, который затем перерабатывается в инструменты;
- miner добывает из `ResourceNodeC{Node: NodeMine, Stock}`, то есть его предусловие — запас руды в шахтном узле, а не склад уже добытой руды.

Это может давать обе ложные подписи: шахта пустая, но складская руда есть → «в шахте за рудой»; шахта полна, но склад пуст → «жила скудеет». Предлагаю разделить сигналы `oreInStore` и `mineAvailable`, второй считать по NodeMine.Stock.
