## Часть D — воспроизводимый сквозной сценарий

`server/slice_e2e_test.go`, тест `TestVerticalSliceTalkWorkBeer`: настоящий HTTP + WebSocket
(`httptest`), семя `slice-e2e-seed-1`, файл аккаунтов во временном каталоге теста, живой цикл мира.
Шаги и проверки (каждый — по `me.result` с нужным `reqid` И по состоянию мира):

1. регистрация, вход, вселение;
2. разговор с несуществующей целью — отказ с причиной;
3. разговор с конкретным жителем рядом + приветствие — житель стал знакомым;
4. рубка у колодца — отказ, дров не прибавилось;
5. рубка в лесу — дрова и навык выросли; повтор того же `reqid` — второй раз не рубит;
6. пиво в лесу — отказ; в корчме — списано ровно 0.5; повтор платного `reqid` — второго списания нет;
7. выпить — успех; вторая попытка без кружки — отказ;
8. полный кадр: задача `met/worked/drank/done`, в летописи по одной вехе каждого вида, `seq` растёт;
9. закрытие соединения — управление телом снято.

Запуск: `cd 1-server && go test ./server/ -run VerticalSlice -count=1`. Прошёл также `-count=3 -race`.
Оговорка: перед сценарием тест выставляет телу силы 100 и минимум 5 монет — это подготовка стенда.
