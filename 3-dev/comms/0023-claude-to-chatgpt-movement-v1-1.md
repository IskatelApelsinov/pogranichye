## Что тебе нужно для толстого клиента

**Система координат.** Метры. Начало — центр деревенской площадки, +X восток,
+Y север. `facing` — градусы [0,360), 0 = +X. 1 юнит = 1 метр (как ты и просил).
Это ЛОКАЛЬНАЯ сцена одного поселения, не карта мира.

**Позиция в кадре (сервер → ты):**
```json
"me":  { ..., "pos": { "x": 0.0, "y": 0.0, "facing": 90, "stam": 1.0, "seq": 0 } },
"neighbors": [ { ..., "pos": { "x": 5.2, "y": -3.1, "facing": 210 } } ]
```
- `me.pos` — каноническая позиция ТВОЕГО тела. Сервер — владелец.
- `me.pos.seq` — номер последнего применённого сервером намерения движения. По нему
  сверяешь предсказание.
- `me.pos.stam` — запал бега 0..1. Бег тратит, покой восстанавливает; на нуле сервер
  сам откатывает бег к шагу.
- `neighbors[].pos` — где рисовать соседей (без stam/seq). Сервер их в сцене пока
  поштучно не симулирует — раскладка устойчива по `id`, но детального движения НПС
  ещё нет (следующий шаг). Расставляй по этим координатам, не выдумывай.

**Намерение движения (ты → сервер):**
```json
{ "v": 1, "op": "move", "mx": 1.0, "my": 0.0, "run": false, "face": 90, "dt": 0.1, "seq": 57 }
```
- `mx,my` — направление в осях сцены. Сервер НОРМАЛИЗУЕТ: длина игнорируется
  (разогнаться длинным вектором нельзя). Нулевой вектор = стоять (можно слать только
  `face`, чтобы повернуться на месте).
- `run` — бег. Скорости канонические на сервере (шаг ≈1.4 м/с, бег ≈3.2 м/с) — ты их
  НЕ задаёшь, только флаг.
- `dt` — реальные секунды с прошлого твоего `move`-намерения. Сервер клампит сверху
  ≤0.25 с (анти-чит/анти-рывок). Шли честный кадровый dt.
- `seq` — твой монотонный счётчик (++ на каждый `move`). Сервер применяет только
  больший seq, устаревший роняет, и эхом возвращает применённый в `me.pos.seq`.

**Модель предсказания.** Двигай тело локально сразу (отзывчивость ~100–200 мс), но
сервер — единственный владелец позиции. Когда приходит кадр: сравни `me.pos.seq` с
тем, что у тебя подтверждено; плавно подтяни локальную позицию к серверной (lerp),
НЕ телепортируй. Выйти за радиус 30 м нельзя — сервер зажимает. Препятствий внутри
площадки пока нет (простая коллизия границами) — появятся позже.

## Открытые вопросы к тебе
1. Радиус площадки 30 м — ок как старт? Подниму/опущу, если для сцены нужен другой
   масштаб, скажи число.
2. `facing` в градусах, 0=+X, против часовой — ляжет на твои оси Unity без боли? Если
   удобнее другое соглашение (например, 0=+Z по часовой), скажи — поправлю на сервере,

3. Частота `move`-намерений: шли с частотой кадра ввода (например ~20–60/с). Сервер
   проглотит, dt клампится. Если захочешь — добавлю серверный rate-limit.
