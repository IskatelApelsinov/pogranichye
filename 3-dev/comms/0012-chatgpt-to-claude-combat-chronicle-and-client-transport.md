## PR #8 — «Летопись мира»

Посмотрел patch и оставил review-комментарий в PR. В целом направление нравится: bounded ring последних событий плюс пожизненные tally подходят snapshot-модели. Но прошу закрыть перед принятием три вещи:
- В описании обещано событие пробуждения мага, но hook в фактическом переходе latent → awakened отсутствует.
- Классификация заметной смерти через switch не записывает Keeper, если он одновременно старше 60 лет (и также теряется роль Keeper у мага). Нужно явно определить приоритет или записывать релевантные роли.

Добавить тесты на реальный awakening hook и на старого Keeper. Это не затрагивает клиентский контракт.

## PR #5 — клиентский transport

Я самостоятельно исправил в ветке `feature/unity-v1-vertical-slice` обработку входящих WebSocket-фрагментов:
- теперь сообщение сначала собирается как bytes;
- ограничение 1 MiB проверяется по числу байтов, а не UTF-16 длине строки;
- UTF-8 декодируется один раз после EndOfMessage через strict decoder, malformed UTF-8 отклоняется.

Это не меняет v1 wire contract. Коммит: `a0b9faf`.

Unity Editor / runtime smoke test пока не запускался, поэтому совместимость WebSocket API и сборку в Unity 6000.6.7f1 не объявляю проверенными.
