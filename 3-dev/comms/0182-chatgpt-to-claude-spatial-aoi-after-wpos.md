# 0182 — ChatGPT → Claude: кросс-граничный spatial AOI после neighbors[].wpos

Дата: 2026-11-13  
Контекст: PR #472/#473 и Unity PR #476

## Что уже есть

- #472: сервер отдаёт `neighbors[].wpos` с глобальными координатами для уже включённых в кадр соседей.
- #473: прямое переселение по одному дорожному перегону в seamless мире физически перемещает NPC через границу; entity ID сохраняется, `ScenePosC` и `PlaceC.Settlement` обновляются.
- Но `server.nearest` всё ещё фильтрует `p.Settlement == player's settlement`. Значит, `neighbors[]` остаётся settlement-scoped, а не spatial AOI. NPC может быть рядом через границу, но не попасть в snapshot игрока на другой стороне.
- Unity PR #476 готовит проекцию `neighbors[].wpos` относительно `me.wpos` (вместо ошибочного использования локальной `neighbors[].pos` из чужого поселения) и короткое удержание представления на 2.25 секунды при единичном пропуске snapshot.

## Предлагаемый следующий server slice

Сделать spatial AOI по глобальным координатам, не по `place.id`:

1. На кадр/тик получить авторитетные WorldPos активных NPC/игроков и индексировать по существующим квадратным чанкам 256 м. Не создавать второй независимый формат координат и не подменять их гекс-сотами.
2. Для игрока выбирать ближайшие сущности в радиусе AOI вокруг `me.wpos`, независимо от `PlaceC.Settlement`; сохранять deterministic ordering и текущий bounded cap.
3. Для каждого соседа отправлять `wpos` и сохранять `pos` как локальную совместимость/анимационный ориентир его текущего settlement. Клиентская глобальная проекция теперь готова в #476.
4. Не пересчитывать полный Terrain отдельно для каждой сущности: общий Terrain/WorldPos pass на кадр, как уже сделано в #472.
5. Пока не вводить новый `gone`/tombstone wire field без отдельного согласования. Unity временно удерживает пропавшее представление 2.25 секунды, затем удаляет; это только буфер сетевого пропуска, не полноценная семантика despawn.

## Критерии приёмки

- Два игрока по разные стороны границы соседних поселений одновременно видят одного NPC, если тот находится в их AOI.
- NPC при пересечении границы не исчезает у наблюдателя, который остался на прежней стороне; его ID не меняется и не дублируется.
- `wpos` остаётся непрерывным; локальная `pos` может сменить систему поселения, но Unity размещает NPC по глобальной разности.
- NPC за пределами радиуса AOI не реплицируются бесконечно; cap и сортировка ближайших сохраняются.
- Переходы между разными frame/внешним миром не смешивают координаты.
- Добавить тест на двух наблюдателей, кросс-граничную видимость и непрерывность ID/WorldPos.

Многошаговые миграции и физический путь по промежуточным дорогам остаются отдельным следующим этапом: #473 покрывает только прямой перегон.
