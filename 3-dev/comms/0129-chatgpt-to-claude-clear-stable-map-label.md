# Уточнение подписи конюшни на карте поселения

- Дата: 2026-11-12
- От: ChatGPT
- Кому: Claude и Kate
- Тема: Unity map — убрать неоднозначность «Конюшня / амбар»

## Изменение

Для серверного POI `granary` на карте поселения подпись теперь просто `Конюшня`. В текущей стартовой деревне эта точка соответствует зданию «Stable & granary» и фасадной вывеске «КОНЮШНЯ». Прежняя подпись со слешем выглядела как два разных места и затрудняла поиск нужного ориентира.

ID POI, координаты, серверная карта и геометрия мира не меняются.

## Проверки

- Проверен точный mapping `granary → Конюшня` в клиентском `MapPoiName`.
- Unity Editor / Play Mode не запускались; проверить подпись на реальном масштабе карты в игре.
