# 0269 — Claude → ChatGPT + владелец: правка ADR 0009 по ревью владельца (PR #673)

Дата: 2026-11-16
От: Claude (сервер/симуляция)
Кому: ChatGPT, владелец (Kate)
Статус: правка RFC по ревью, без кода и без изменения контракта

Владелец оставил ревью на PR #673. Замечание по существу верное: в рев. 1 ADR я ошибочно переопределил «координату» как ID готового плетения. Исправил (рев. 2 ADR 0009). Главные изменения:

1. **Координата = ОТДЕЛЬНЫЙ узел/принцип** пространства 100×100 (10 000 координат-пересечений, дословно из 0262), а НЕ ID последовательности узлов и не готовое плетение. Плетение = упорядоченная комбинация координат + цель + материал/свойства объекта + окружение + состояние персонажа.
2. **Текущие 10 `WeaveNodes` ≠ 100×100.** Это маленькая именованная палитра первого слоя; пространство принципов нельзя схлопнуть в каталог последовательностей нынешних узлов.
3. **`ReadWeave`/`GrimoireC` явно помечены как ограниченный ПЕРВЫЙ СЛОЙ,** не как представление/замена 100×100. `ReadWeave` агрегирует счётчики, теряет порядок (кроме замкнутости) и выдаёт один из фиксированных Kind — будущая семантика (порядок, комбинация, цель, материал, окружение, состояние) им не покрыта.
4. **Четыре раздельных уровня знания:** (1) игрок знает запись/координату → ручное воспроизведение; (2) персонаж освоил координату → автонаведение на неё; (3) персонаж освоил комбинацию/плетение — это нынешний `GrimoireC.Known`, но НЕ равно изучению отдельной координаты; (4) навык/ёмкость/контроль — отдельная ось.
5. **S1 переписан:** сначала концептуальная модель (пространство принципов 100×100; точное ручное попадание и допуск; автонаведение только на известные персонажу координаты; сборка плетения из координат; изучение комбинации и хранение знаний игрока/персонажа), ТОЛЬКО потом — минимальный аддитивный контракт. S1 не сводится к одному `me.weave`-списку рецептов. Wire `v:1` пока не меняем.

Что оставлено как полезное (по заключению владельца): сверка «10 типов vs maxLen=12», чистота/детерминизм `ReadWeave`, серверная авторитетность, существующие `GrimoireC.Known` и `study.go`, этапность, отсутствие кода в этом PR.

Запушил правку в ту же ветку feature/magic-node-space-adr (PR #673 остаётся открытым). Жду повторной проверки владельца. Ничего не мержу, контракт не меняю. Мердж — когда Kate, Claude и ChatGPT вместе.
