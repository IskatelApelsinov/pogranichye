# 0195. ChatGPT → Claude: сквозная проверка рынка и инвентаря для демо

Дата: 2026-11-13
Связано: 0192, 0194, PR #512, `sim/expansion.go`, `server/server.go`, `CoreGameplay.cs`.

## Цель

Закрыть пробел между unit-тестами экономики и реальным клиентским маршрутом. Не расширять механику рынка; проверить, что текущий контракт действительно работает через HTTP + WebSocket.

## Требуемый E2E

Добавить отдельный детерминированный серверный тест (или аккуратно расширить существующий vertical slice), который через реальный HTTP/WS:

1. Регистрирует/логинит игрока, входит в поселение и получает полный snapshot.
2. Покупает один товар через `op:trade`, `side:buy`, с заранее выставленным наличием товара и монетами. Проверяет `me.result` с тем же reqid, списание монет, уменьшение `place.store` (если поле доступно) и увеличение `me.stash`.
3. Повторяет тот же reqid и доказывает, что баланс/запасы не меняются повторно.
4. Продаёт товар обратно через `op:trade`, `side:sell`; проверяет уменьшение `me.stash`, пополнение рынка и зачисление монет с учётом комиссии.
5. Покупает инструмент через `op:take` у правильного POI (например, топор в woods или удочку у river). Проверяет `me.inv.items`, списание монет и зачисление казне поселения.
6. Повторяет тот же reqid; предмет и деньги не дублируются.
7. Проверяет отрицательные случаи: неверный POI, недостаток монет, неизвестный товар/сторона, пустой reqid. Отказ не должен менять ни одну сторону сделки.
8. Подтверждает, что рыночный товар находится в `stash`, инструмент — в `inv.items`, а не наоборот.

## Проверить клиентский контракт

- Сверить `CoreGameplay` UI: кнопки/цены/условия не должны показывать товары из `stash` как экипировку.
- Убедиться, что `RequestGate` коррелирует ответ с правильным reqid, а UI перечитывает авторитетный snapshot, а не оптимистично добавляет предмет.
- Если цена в UI дублируется локальной таблицей, явно зафиксировать это как временное ограничение; не менять wire без ADR.

- Новый тест проходит в CI.
- В PR приведены конкретные команды и фактические результаты.
- Проверены изменения состояния мира, не только `me.result`.
- Повтор reqid не дублирует ни списание, ни товар.
- Wire v1 остаётся совместимым, если нет отдельного ADR.
