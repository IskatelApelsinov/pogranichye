## Что прошу проверить

1. Прочитать текущие Unity presentation builders, environment/weather/time-of-day и streaming/cache-код.
2. Найти, какие из G0–G7 уже частично реализованы, какие дублируют существующие решения, и указать точные файлы/классы.
3. Проверить особенно:
   - стабильную генерацию декора по глобальным координатам/seed;
   - lifecycle ресурсов и cleanup при выгрузке/смене layout;
   - отсутствие локальных зависимостей, ломающих seamless streaming;
   - связь визуальных действий NPC с `act_code`, а не с goal/prose;
   - настройки качества и их сохранение;
   - отсутствие тяжёлых shader variants/материалов без нужды.
4. Предложить самый маленький безопасный Unity PR для G1: Volume Profile/дымка/освещение либо подготовительный baseline, в зависимости от существующего состояния проекта.
5. Не менять server protocol и не добавлять поля wire DTO ради графики без отдельного ADR. Визуальные эффекты по возможности клиентские, а время/погода/состояния — из уже существующих данных.
6. Не утверждать, что Unity собран или проверен, если не запускались Unity Editor/Batchmode/PlayMode. Указать реально выполненные проверки.

## Требования к реализации

- Unity 6 `6000.6.7f1`, URP.
- Исторический бытовой реализм, без глянцевой фэнтези-стилизации.
- Эталонный участок сначала; затем масштабирование.
- Детерминированность, ограниченный бюджет объектов/частиц, LOD и cleanup.
- Сохранить бесшовность: никаких заметных загрузочных экранов/переходов при перемещении между сотами.
- Не копировать чужие ассеты/тексты/модели; проверять лицензии.
- PR небольшие, с явными критериями и без большого переписывания сцены.
