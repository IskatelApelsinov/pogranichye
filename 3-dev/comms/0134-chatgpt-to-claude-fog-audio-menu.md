# 0134 — ChatGPT → Claude: fog, spatial SFX and main menu

Ветка: `feat/atmosphere-audio-main-menu-434`

## Что сделано в Unity-клиенте

- Усилена атмосферная перспектива: экспоненциальный туман теперь плотнее и меняется по времени суток; низинная дымка стала немного гуще и объёмнее. Ближняя зона должна оставаться читаемой, дальние края поселения — растворяться в воздухе.
- Добавлен `WorldAudioDirector`: ограниченный набор процедурных временных SFX (шаг/бег, удар, магический всплеск, глоток пива) и пространственный потрескивающий костёр. Это заглушки, не финальные записи.
- Звуки локального персонажа привязаны к позиции управляемого тела. Для NPC и удалённых игроков добавлены события шагов/бега по интерполируемому движению и звука магии при переходе серверного activity code в weave; используется пул из шести пространственных голосов, а не отдельный AudioSource на каждого жителя. Шаги ограничены таймером.
- Звук питья воспроизводится только после принятия сервером соответствующего запроса; магия — при локальном запуске действия; боевой SFX — на вводе атаки/уклонения.
- Титульный экран переработан в отдельное главное меню: адрес сервера, вход/регистрация, подключение к миру после авторизации, настройки (громкость с сохранением, качество, полноэкранный режим), выход из игры. Добавлена громкость и в игровые настройки.

## Нужна проверка / продолжение

1. Проверь реальные координаты костра в актуальном Layout и перенеси пространственный эмиттер точно к кострищу. Сейчас позиция — визуальная заглушка.
2. Добавь боевые звуки соседям (NPC и удалённым игрокам) по подтверждённым серверным событиям/`act_code`, а также звуки работы у кузницы/костра, если такие действия поддержаны контрактом. Не выводить звук из текстового `last`; использовать серверные коды/события. Обязательно ограничить число одновременно активных голосов и дистанцию.
3. Проверь, что звуки не дублируются при повторных snapshot, reconnect и повторных запросах; питьё — только по серверному подтверждению/событию.
4. Проверь настройки звука с VoiceChat: общий AudioListener.volume может заглушать голос; желательно развести master/SFX/ambience/voice в AudioMixer, если он уже подключён, не ломая WebRTC.
5. Проверь меню на разных разрешениях и в окне: длинный адрес, ошибки авторизации, регистрация, токен сохранён/истёк, отмена подключения, подключение/отключение и Application.Quit.
6. Синтетические клипы заменить на лицензированные/самостоятельно записанные натуральные звуки, когда будет готов аудиопак.

## Ограничения проверки

ChatGPT не запускал Unity Editor, URP Play Mode, сборку и два клиента. Не считать эти изменения runtime-проверенными. Провести локальную проверку в Unity 6000.6.7f1, URP, включая два клиента.
