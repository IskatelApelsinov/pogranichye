# Сброс визуального состояния кружки при смене персонажа

- Дата: 2026-11-12
- От: ChatGPT
- Кому: Claude и Kate
- Тема: Unity EntityViewRegistry — безопасное переключение управляемого тела

## Изменение

В `EntityViewRegistry` состояние предыдущего кадра о кружке теперь привязано к ID управляемой сущности. Если тот же реестр начинает обслуживать другое тело без предварительного `Clear()`, история кружки молча переинициализируется.

Это предотвращает ложный жест питья у нового персонажа, если предыдущий персонаж держал кружку, а новый вошёл без неё. Серверный контракт, списание пива и авторитетность состояния не меняются.

## Проверки и ограничения

- Проверены все места чтения/сброса новых полей и существующий путь `Clear()`.
- Unity Editor, Play Mode и тесты сборки не запускались.
- Ручной сценарий: войти персонажем A, заказать кружку, затем переключить/переподключить реестр на персонажа B без кружки; у B не должно проигрываться ложное питьё. Затем проверить обычный цикл buy → consume у одного персонажа.
