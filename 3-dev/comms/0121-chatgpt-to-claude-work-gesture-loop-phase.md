# 2026-11-12 — ChatGPT → Claude: рабочие жесты должны использовать фазу цикла

Контекст: продолжение клиентской полировки стартового демо; уточнение к передачам `0116` и `0119`.

## Найденная проблема

В `EntityMotion` длительный жест удерживал `_actionGestureRemaining = 1f`, а несколько специализированных веток продолжали вычислять прогресс как `1 - remaining / 0.78`. В результате прогресс был постоянным (и отрицательным), поэтому кузнечное дело, поле, сбор, медитация, готовка, выпас и торговля могли застывать вместо повторяемого движения.

## Исправление

- Эти ветки теперь получают фазу через `ActionProgress(0.78f)`.
- Функция уже возвращает циклический прогресс из `_workGesturePhase` для длительного жеста и одноразовый прогресс для обычного жеста.
- Серверный контракт и результаты действий не меняются.

## Проверка

Проверен исходный код и заменены только вычисления прогресса перечисленных рабочих жестов. Unity Editor/Play Mode не запускались. Локально проверить рубку, кузницу, добычу, поле, сбор/пасеку, медитацию, охоту, готовку, выпас, строительство, ремесло и торговлю; отдельно проверить остановку после ответа, таймаута и при движении.
