## Принятые координатные правила

- `space.origin`, `space.bounds`, `rooms[].bounds`, порталы — глобальные E/N/U метры.
- `surfaces[].points` и `stairs[].points` — локальные метры от `space.origin`: x=East, y=Up, z=North.
- `place.anchor` — географический центр поселения; локальные Unity-координаты получаем разностью глобальных double до преобразования во float.
- `me.wpos` и `neighbors[].wpos` — канонические мировые позиции. `pos` — локальные координаты текущего поселения; при переходе между землями могут пересчитываться.
- `me.wpos.space_id/level_id` — семантические идентификаторы для UI/анимации/аудио, не разрешение менять высоту или этаж.
- 1 единица пути/«верста» в экономике = 250 м. Не показывать такие числа как километры; реальные поля `dist` в метрах (например, близость каравана) не пересчитывать повторно.

## Что сделано в Unity PR #674

1. `WorldSpacePresentationBuilder` строит серверные поверхности и лестницы. Точки не переставляются: Unity Vector3 = (x,y,z) = (East,Up,North). `space.origin` смещается относительно текущего settlement anchor.
2. Добавлено кэширование descriptors по чанкам. При смене settlement anchor пространства очищаются и пересобираются из кэша; при выгрузке чанка удаляется соответствующая геометрия.
3. Кровля корчмы не создаётся процедурно второй раз: используется server-authored `roof` surface. Другие footprint-only здания пока сохраняют свои визуальные fallback-крыши.
4. Акустика строится по `rooms[].bounds`. `cave`, `tunnel`, `cellar` получают Cave reverb; остальные комнаты — Room.
5. Этажи, лестницы и порталы только отображаются. `stairs.kind=ramp` рендерится непрерывным скатом, обычные stairs — ступенями, вертикальные сегменты — перекладинами. Primitive colliders лестниц сразу отключаются и удаляются. Никаких локальных телепортов, локальной смены высоты или переходов между уровнями; surface colliders не являются разрешением серверного движения.
6. Начальная позиция игрока, NPC и карта поселения используют `wpos` относительно `place.anchor`. Локальный `pos` остаётся только fallback для старых серверов и локального same-settlement movement/replay.
7. Добавлены DTO для `place.realm`, `place.caravans`, `place.sites[].note`, `/api/world.realms`, `/api/world.caravans`, `/api/world.movement`.
8. Карта показывает державу, обозы, следы ходоков в урочищах. Длины дорог из единиц карты показываются в метрах (умножение на 250), не в километрах.
9. Предсказание шага повторяет серверную `SlopeMult` и использует `probe_m`, `flat_radius_m`, коэффициенты из `/api/world.movement`. Высота берётся из загруженных server terrain chunks с bilinear sampling; пока чанк не загружен, slope prediction не выдумывает локальный рельеф и ждёт серверную коррекцию.

## Что НЕ делаем до S4

- Не разрешаем подниматься по лестницам, входить в погреб, башни и пещеры только по локальным colliders.
- Не изменяем `ScenePosC.Z`, не генерируем локальные переходы и не делаем клиентскую навигацию авторитетной.
- Не переопределяем `me.room.indoor`.
- Не переводим экономические единицы пути в километры и не меняем сохранённые значения.

## Звуковая среда

- Текущие VillageSoundscape/WorldAudioDirector остаются presentation layer; серверные activity codes, biome, water, rooms и building identity задают контекст.
- Процедурные ambience placeholders не выдаются за полевые записи.
- Если появится стабильный server soundscape/building kind, подключим его аддитивно; не нужны отдельные аудиособытия вместо состояния мира.
