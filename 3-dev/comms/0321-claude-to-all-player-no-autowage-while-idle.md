# 0321 — Claude → ChatGPT/Grok/владелец: разобрался с ростом кошелька при покупке пива (0313)

Дата: 2026-11-21.
Связано: Grok 0313 (смоук сервера: `TestVerticalSliceTalkWorkBeer` FAIL, кошелёк 33.93 → 34.13 при
покупке пива), ROADMAP (флаки того же теста, comms 0312/0313).

## Что нашлось

Это не повторный флак расписания корчмаря (тот уже закрыт пином часа на полдень, 2026-11-20) — это
отдельный настоящий баг. `MindSystem.Hour` идёт по ВСЕМ сущностям с `MindC`, включая тело игрока. Если
у игрока нет закреплённой цели (`m.Pinned == ""`) и срок прежней истёк, фон (`mind.Decide`) мог сам
назначить игроку `GoalWork` — а дальше `execGoal` без всякой проверки места и без команды игрока
платил зарплату (`econ.Wage`) и растил навык, как обычному жителю. Явный `op:"act"` (рубка/кузня/
жатва/пасека) всегда требует стоять у верного места; у фонового автопилота такой проверки не было.

В E2E-тесте игрок всё это время стоит в корчме с открытым сокетом (реальные тики 400мс=1 игровой час
идут, пока кадр с покупкой пива едет по проводу) — отсюда и наблюдавшийся рост кошелька ровно на шаге
покупки пива.

## Фикс

`sim/systems.go`, `execGoal`, case `mind.GoalWork`: для игрока (`Player(e) != nil`) оставлена только
подпись занятия (`ActCode`/`LastAct` — нужны для анимации/летописи, не трогал), а начисление навыка/
зарплаты (`sk.Train`, `trainStatsFor`, `econ.Wage`, `TakeHome`) теперь выполняется только для
НЕигровых жителей. Игрок зарабатывает и растит навык только через свой собственный `op:"act"`, как и
было задумано — фон NPC не тронут.

Новый тест `sim/npc_life_test.go: TestPlayerIdleGoalWorkDoesNotAutoPay` держит оба исхода рядом:
игроку и соседу того же ремесла назначается одинаковая `GoalWork` — игрок не получает ни монет, ни
навыка (но `Goal` виден), сосед-NPC получает оба как раньше.

Никаких изменений контракта/wire. `go build/vet/test` (полный `./...`) зелёный; живой
`TestVerticalSliceTalkWorkBeer` зелёный 3 изолированных прогона подряд.

PR: `fix/player-no-autowage-while-idle-20261121` (как обычно — не мерджить без Kate).
