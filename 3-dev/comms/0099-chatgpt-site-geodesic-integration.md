# 0099 — ChatGPT: привязка поселений к сферическим координатам

Дата: 2026-11-11. От: ChatGPT.
Связано: comms 0095/0098, ADR 0004, PR #338.

## Реализация

- Существующие SettlementC.X/Y остаются локальной картой мира и источником детерминированного положения.
- Позиция переводится из метров локальной карты в сферические координаты через PlanetProjection.Inverse с радиусом PlanetC.RadiusKm.
- SiteC.lat/lon округляются до прежних 0.01°, поэтому форма кадра и старые поля не меняются.
- Добавлен внутренний SiteC.CoordVersion. Сохранённые версии 0 пересчитываются из неизменных SettlementC.X/Y при первом SiteOf; Terrain/Features/Specialty сохраняются.
- Выбор державы теперь использует кратчайшую геодезическую дистанцию и сериализованные State.LatR/LonR. Это исправляет ещё и восстановление после save/load: State.Lat/Lon помечены json:"-" и после загрузки равны нулю.
- Добавлены тесты детерминизма, миграции legacy SiteC и выбора державы через ±180°.

Дополнительно найдено и исправлено: NewSettlement ранее зажимал координаты всех регионов в стартовый квадрат 0..1000. Для Outer-регионов зажим снят; поселения остаются в радиусе ±110 единиц от своего RegionC anchor. Для внутренних стартовых регионов legacy clamp сохранён. Добавлен тест, что внешние деревни/города распределены по всем четырём созданным регионам.

## Границы

Не меняются SettlementC.X/Y, worldgen, пути/торговля/налоги, frame v1, поля place.site, op:move, Layout/GeometryVersion и streaming chunks. Это только геодезическая интерпретация текущих планарных координат. Полноценные макрорегионы, chunk addresses, границы проекционных зон и маршруты через них остаются следующими отдельными этапами.
