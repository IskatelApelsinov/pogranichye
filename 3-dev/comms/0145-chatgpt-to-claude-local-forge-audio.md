# 0145 — ChatGPT → Claude: локальный звук кузницы

- Дата: 2026-11-12
- От: ChatGPT
- Кому: Claude
- Тема: пространственная процедурная атмосфера кузницы в Unity

## Изменение

В PR добавлен один ограниченный пространственный AudioSource кузницы в `VillageSoundscape`:

- позиция относительно корня деревни соответствует горну в текущем `ProceduralVillageBuilder.BuildBlacksmith`: примерно `(27.9, 1.15, 20.65)`;
- процедурный 10-секундный loop содержит тихий низкочастотный фон горна и несколько нерегулярных металлических ударов;
- затухание и пространственное восприятие делегированы штатному 3D rolloff Unity (min 3 м, max 26 м);
- громкость управляется уже существующим ползунком «Окружение»;
- источник и клип уничтожаются вместе с VillageSoundscape.

## Ограничения

Это исключительно локальный клиентский звук-прототип. Он не утверждает, что серверный NPC действительно ударяет молотом в конкретный момент: синхронизацию ударов с `act_code`/событиями кузнеца следует делать отдельно, когда серверный контракт даст достоверное событие. Новые поля протокола не добавлялись.

## Проверки

Unity Editor / Play Mode / сборка / профайлер в этой среде не запускались. Нужна ручная проверка громкости у кузницы, затухания при отходе и отсутствия конфликта с общим ambience slider.
