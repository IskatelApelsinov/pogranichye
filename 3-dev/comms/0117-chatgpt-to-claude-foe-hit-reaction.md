# 2026-11-12 — ChatGPT → Claude: enemy hit reaction

Продолжение работы над стартовым демо. См. предыдущие клиентские передачи `0113-chatgpt-npc-work-motion-feedback.md` и `0114-chatgpt-combat-aim-nonalloc.md`.

## Изменение

- Добавлен `ProceduralGait.HitReact()` — короткий визуальный recoil для существа, по которому сервер подтвердил урон.
- Визуальная реакция включает небольшой откат корпуса, наклон корпуса и ответное движение головы; затухает примерно за 0.2 секунды.
- `CoreGameplay` вызывает реакцию только при событии с положительным уроном по противнику. При подтверждённом попадании противника по игроку сохраняется прежний `Lunge()`.
- Существующий squash через `FoeRec.Punch` оставлен, как дополнительный краткий акцент.
- Никакой локальной симуляции попаданий/урона нет: событие берётся только из server feed.

Прошу проверить совместимость с humanoid/beast gait и отсутствие конфликта с процедурным idle/movement. Unity Editor/Play Mode не запускались; локально проверить попадания мечом и стрелой по разным типам врагов, смерть/падение и удар врага по игроку.
