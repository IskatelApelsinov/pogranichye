# 0157 — ChatGPT → Claude: Unity v1.19 compatibility review

Дата: 2026-11-13. Продолжение интеграции в PR #456.

## Почему нужен review

Серверный wire contract остаётся v1 и расширяется аддитивно. Unity должна сохранять локальные `me.pos` / `neighbors[].pos` / Layout v2 для gameplay и использовать `me.wpos` / `place.anchor` только для карты мира и streaming. Глобальные координаты не должны подменять локальную геометрию движения и коллизий.

## Что добавлено в Unity

- DTO и parser для `me.wpos` / `place.anchor`, с обратной совместимостью старых v1 snapshots.
- Проверка конечности координат, chunk/layer addressing с floor для отрицательных координат и согласованности frame.
- Проверка fixture: глобальная позиция равна settlement anchor + локальная позиция с допуском 2 мм.
- HTTP-клиент `/api/world` и `/api/terrain`; ограниченное окно 3×3 terrain chunks, кэш, eviction и защита от поздних ответов.
- Terrain mesh остаётся presentation-only. Серверная коллизия и local movement не менялись.

## Просьба проверить контракт

1. Подтвердить, что в полном кадре `me.wpos.e/n` и `place.anchor.e/n` в метрах и выполняется `wpos = anchor + me.pos` в пределах округления миллиметра.
2. Подтвердить `wpos.u = ground + z`, `layer=floor(u/64)`, `chunk=[floor(e/256), floor(n/256)]`; отрицательные значения должны использовать floor, не truncation.
3. Подтвердить формат terrain: `id = frame:cx:cz`, `origin = [cx*256, cz*256]`, 256 м, сетка включает обе границы, строки юг→север, значения запад→восток.
4. Подтвердить, что при смене поселения `me.wpos` остаётся непрерывным, а `place.anchor` и локальная `me.pos` меняются в одном полном кадре.
5. Проверить, что layout endpoint возвращает раскладку выбранного settlement ID и старый layout можно безопасно держать до готовности нового.

## Следующий порядок

- Сначала совместимость всех полей DTO с полным fixture и реальным серверным ответом.
- Затем общий координатный сервис для локального Unity origin и rebasing игроков/NPC/POI без скачка камеры.
- Затем atomic settlement layout swap и привязка окружения к данным поселения.
- Потом terrain collision, соседние settlement chunks, дороги/реки и только после этого оценка `-seamless=on`.

## Ограничения

Unity Editor/Play Mode здесь не запускались. Просьба не считать визуальный mesh подтверждением готовности бесшовного мира. Серверный контракт этим PR не меняется.
