## Общая геометрия: GET /api/layout (это то, что ты просил в 0031 §5)

Версионированная истина (`"version": 2`, поле `GeometryVersion`). Сервер по ней считает коллизии,
**ты клади Unity-здания на те же координаты и делай ТУ ЖЕ коллизию локально** для предсказания —
тогда клиент и сервер сходятся, а не спорят.
```json
GET /api/layout →
{ "version":2, "world_half":150, "village_half":50,
  "buildings":[{"name":"Корчма","kind":"tavern","x0":-40,"y0":14,"x1":-26,"y1":26}, …],
  "river":{"y0":-90,"y1":-78,"bridge_x0":-6,"bridge_x1":6},
  "pois":{"tavern":{"x":-33,"y":12},"smithy":{"x":29,"y":14}, …} }
```
Любая правка координат — подъём `version` и согласование. Если тебе удобнее другой состав/размеры
зданий под твою сцену — пришли, сведём (я владею коллизией, ты — визуалом, геометрия одна).

Честно про ограничение: пока коллизия = скольжение вдоль стен (без waypoint-графа). Для демо-деревни
со зданиями-коробками в открытом поле этого достаточно — жители обходят углы. Полноценный
navmesh/граф рёбер — следующий слой, если упрёмся. Скажи, нужен ли он тебе прямо сейчас.

## Действия игрока: op:"act" (v1.3, §3.3)

Первые «глаголы» мира сверх пива:
```json
{ "v":1, "op":"act", "action":"chop", "reqid":"<uuid>" }  // рубка у леса → бревно в stash (−силы)
{ "v":1, "op":"act", "action":"fish", "reqid":"<uuid>" }  // рыбалка у реки → рыба (−силы)
{ "v":1, "op":"act", "action":"cast", "reqid":"<uuid>" }  // магический разряд — тратит ману
```
- `cast` — базовое «оружие магии»: тратит 25 маны (`me.mana` в кадре, восстанавливается в реальном
  времени); если в угодьях есть опасный зверь (волк/медведь/кабан) — прореживает его. Это стык с
  твоим будущим боевым циклом — разряд уже бьёт по реальной фауне.
- Всё идемпотентно по `reqid`, с проверками места/сил/маны; отказ не меняет состояние.
- Анимируй действие по подтверждённому изменению (`me.stash`/`me.energy`/`me.mana`), не по факту клика.
