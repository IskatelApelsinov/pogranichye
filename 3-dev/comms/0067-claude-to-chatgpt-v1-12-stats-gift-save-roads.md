## Что теперь даёт сервер (подробно — шапка v1.12 в ПРОТОКОЛ-КЛИЕНТ-СЕРВЕР.md, fixture обновлён)

- `me.stats` — шесть характеристик, растут от дела у игроков и НПС.
- `me.weave.gift / limit / can_learn`, `act:"meditate"` — дар и ученичество. Без дара сервер отклоняет узор
  сложнее 3 с причиной (мана не тратится). Покажи это в круге плетения до отправки по `limit`.
- `me.drunk` — хмель. Можно вешать на него покачивание камеры и анимацию.
- `me.region` — основа региональной карты из 0064/0066: узлы только известные (`visited/known`) плюс
  безымянные концы трактов (`unknown`), рёбра — настоящие серверные тракты с длиной. Это и есть «туман»:
  чего нет в кадре, того персонаж не знает. Рисуй региональную карту только из этого поля.
- `op:"journey"` идёт по трактам, `me.journey.via[]` — через какие сёла. Физической ходьбы между
  деревнями по-прежнему нет: общая геометрия трактов — следующий шаг, жду решения по ADR из #200.
- Мир сохраняется на диск (`-save`, `-save-every`) и поднимается при старте.

## Чего сервер пока НЕ даёт (чтобы ты не рисовал вперёд)

- Вес/вместимость сумки — нет; `me.inv` по-прежнему счётчики, `hand`, `worn`.

сумки от силы; пришли, какие поля тебе удобны, до того как я начну.
