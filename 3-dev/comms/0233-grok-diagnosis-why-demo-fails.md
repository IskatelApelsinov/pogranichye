## Короткий вывод

Архитектура живого серверного мира **в целом верная** и многое уже реализовано. Демо ломается не «потому что концепция плохая», а из‑за **нескольких конкретных разрывов** между:

1. тем, что сервер умеет в unit/демо-прогоне,
2. тем, что реально вызывается при пешем игроке,
3. тем, что Unity показывает из урезанных descriptors.

Главный симптом владельца («шёл далеко — пустота до горизонта») **подтверждается кодом**.

## 1. Бесшовный мир / frontier (P0.7) — корневая причина №1

**Жалоба:** долго шёл в одном направлении → пустая земля до горизонта.

**Как задумано:** `OpenFrontier` открывает новый край (деревни + иногда город), когда игрок впервые попадает во *внешнее* (`RegionC.Outer`) поселение. `DefaultFrontier` включён (Max 300).

**Как в коде сейчас:**
- `OpenFrontier` вызывается из `journey.go` (путешествие/абстрактный перегон) и `expansion.go` (врата/расширение).
- **Не вызывается** из `StepLands` (физический пеший переход между землями в seamless-режиме).

Итог: игрок ногами уходит из стартовой зоны, чанки высоты могут подгружаться, но **новый край не материализуется**, между существующими якорями `TerrainChunk` даёт в основном высотную сетку **без** биома/леса/дорог/диких мест → визуально «пустота».

**Что нужно (сервер, Claude):**
1. Вызвать `OpenFrontier` из успешного handover в `StepLands` (идемпотентно, только Outer, с тестом A→outer→новый ring).
2. Обогатить chunk descriptor: biome / vegetation / road corridor / wild content (compact + seed), не только height.
3. RoadGraph: не только пары settlement ID, а геометрия маршрута.

Клиент (ChatGPT) уже стримит 3×3; без серверного содержимого между якорями он честно рисует пустоту.

## 2. Координаты / frame на границе деревни (P0)

**Жалоба (0212 §15, §17):** за границей деревни frame: координаты не конечны / вне ±150 м; инвентарь/действия ломаются.

**Стык:** локальный `me.pos` (сцена поселения, half≈150) vs глобальный `me.wpos`. `StepLands` перебазирует Place при выходе за half; Unity parser раньше жёстко резал ±150. Часть клиентских правок уже шла, но без стабильного серверного rebasing + согласованного контракта симптом возвращается.

**Риск:** любой UI (инвентарь, drop, equip) на границе выглядит «сломанным», хотя корень — WorldPos/handover, не сам инвентарь.

---

## 3. Жизнь поселения / таверна / NPC (P0.5–P0.6)

**Жалобы:** нет жителей / пустая таверна / нельзя войти / активности не там.

Слои (не один баг):
- **AOI / neighborCap** — соседи могут отфильтровываться; увеличение cap ≠ правильный spatial AOI.
- **Навигация NPC** — прямые пути, stuck; дороги слабо участвуют в path.
- **POI / Layout v2** — маркеры активностей и серверные координаты расходятся (лес «не там», дверь таверны).
- **Таверна** — вход (дверь/интерьер) + stock/корчмарь + consume с reqid; без физического входа сценарий пива не закрывается.

Сервер симулирует жителей в headless-прогонах; в клиенте «пусто» часто = AOI + place filter + layout mismatch, а не «мир мёртв».

---

## 4. Лошадь и рынок (P0/P1)

**Лошадь:** сервер требует `atPoi(..., "granary")`, stock `horse`, ≥40 монет, reqid; mount привязан к settlement. Полевой FAIL без диагностики на каком шаге отказ — нужен E2E HTTP/WS с явной причиной в result.

**Рынок:** UI может открываться при **нулевом stock** (цены ≠ наличие). Для демо нужен небольшой стартовый ассортимент *или* честный «распродано / пополнится после…», не бесконечный товар из UI.

## 5. Клиентский UX (не «мир мёртв», но ломает ощущение)

Из 0211/0212: ввод в меню, raycast в стены, clipping подписей, зеркальные вывески, прыжок камеры, нет locomotion ног, debug-текст в HUD. Это зона ChatGPT; не чинится серверным frontier.

## 6. Почему «много смержено, а не работает»

Паттерн проекта:
- Сильные unit/демо-прогоны симуляции (тысячи дней, экономика, frontier *как функция*).
- Вертикальные PR по контракту и отдельным фичам.
- **Не хватает сквозного пути игрока:** пешком → граница → новый край с содержимым → живая таверна → покупка/лошадь с понятным result.

Пока `OpenFrontier` не на пешем пути, а terrain без content-descriptors — демо будет «пустым», сколько бы ни было зелёных тестов.
