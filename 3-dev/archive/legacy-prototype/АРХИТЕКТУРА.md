# Архитектура Этапа 1 — модульный мир

## Главный принцип
**Ядро не знает о механиках.** Движок (`world/engine.py`) умеет только две вещи:
крутить время и по очереди вызывать зарегистрированные **системы**. Каждая механика
— отдельный модуль-система. Добавить магию/бой/торговлю = написать новый модуль и
подключить его одной строкой. Ядро при этом не меняется.

## Структура
```
stage1/
  sim.py                  # запуск в терминале (оболочка над world/)
  web.py                  # окно в браузере (оболочка над world/)
  world/                  # ПАКЕТ МИРА
    __init__.py           # сборка движка + набор модулей по умолчанию
    engine.py             # ЯДРО: System (база модуля) + Engine (реестр, цикл)
    model.py              # ДАННЫЕ: Character, Settlement, WorldClock (без логики)
    tuning.py             # все числа баланса (данные, свободно крутить)
    content.py            # ростер, имена, подписи (данные)
    persistence.py        # сохранение/загрузка (мир переживает рестарт)
    systems/              # МОДУЛИ-МЕХАНИКИ
      needs.py            # голод/сон/еда (каждый час)
      work.py             # труд + экономика, utility AI (каждый час)
      consumption.py      # суточный расход, порча, смерть (раз в сутки)
      events.py           # редкие события + новости (раз в сутки)
      weather.py          # ПРИМЕР подключаемого модуля (холода)
```

## Что такое модуль (System)
Объект с необязательными хуками:
```python
class System:
    name = "имя"
    def on_hour(self, world, clock, rng): ...   # каждый игровой час
    def on_day(self, world, clock, rng): ...    # в начале новых суток
```
Движок хранит список систем и зовёт их хуки по порядку. **Порядок = порядок
регистрации** и он важен: нужды до труда (за час), расход до событий (за сутки).

## Как добавить новый модуль (например, магию)
1. Создать `world/systems/magic.py`:
```python
from ..engine import System
class MagicSystem(System):
    name = "magic"
    def on_hour(self, w, clock, rng):
        ...  # своя логика; работает с теми же данными world
```
2. Экспортировать в `world/systems/__init__.py`.
3. Добавить в `DEFAULT_SYSTEMS` в `world/__init__.py` — или подключить снаружи:
```python
engine.register(MagicSystem())
```
Всё. Ядро, другие модули и данные не трогаются.

## Как отключить модуль
```python
engine.unregister("weather")          # в коде
python3 sim.py --no-weather           # демо из терминала
```

## Запуск
```
python3 sim.py --days 40 --seed 3     # хроника в терминале
python3 sim.py --no-weather           # собрать мир без модуля погоды
python3 sim.py --save mir.json        # сохранить
python3 sim.py --load mir.json --days 10
python3 web.py                        # окно: http://127.0.0.1:8080
```

## Принципы, заложенные в фундамент
- данные отдельно от логики (путь к SoA/векторизации и выносу в C потом)
- фиксированный шаг времени, детерминизм от seed
- мировые часы — сохраняемое состояние, не аптайм процесса
- здоровье поселения считается из входов, не хранится (нельзя подделать)
- у вещей есть сток (износ, порча) — «движение вперёд» как сборщик мусора
- производство следует за спросом — деревня находит равновесие сама
- вся машинерия невидима: наружу идут только новости, устами мира
