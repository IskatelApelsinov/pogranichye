# Текстуры 3D-клиента

Сюда кладутся изображения, которые натягиваются на объекты сцены. Имя файла —
контракт: клиент сам подхватит текстуру, если файл есть; если нет — возьмёт
сплошной цвет (ничего не сломается).

Используемые имена:
- `grass.png` — земля (лето)
- `snow.png` — земля (зима/холод)
- `wood.png` — стены домов и таверны
- `roof.png` — крыши

Можно заменить на свои (лучше бесшовные/tileable, квадратные, напр. 256×256 или
512×512, PNG/JPG). Положи файл под тем же именем — Godot импортирует его при
следующем открытии проекта, и он появится в игре.

Где брать бесплатные текстуры (CC0): kenney.nl, opengameart.org, ambientcg.com,
polyhaven.com (раздел Textures). Проверяй лицензию.

Сейчас здесь лежат простые сгенерированные заглушки — их и нужно заменить на
нормальный арт.
