# Установка, обновление и арт (текстуры/модели) — итог мега-итерации

Это итоговая инструкция после большой итерации: как встать на свежую версию, что
проверить, и **что именно качать и куда класть** для текстур и 3D-моделей. Версия
на момент написания — **0.9.10** (в углу обоих клиентов видно, встало ли обновление).

---

## 1. Обновить сервер и прототип (Docker на твоей VM)

```bash
cd pogranichye            # где лежит репозиторий
./manage.sh update        # git pull + пересборка + перезапуск контейнера
./manage.sh status        # проверить, что поднялся
./manage.sh logs          # хвост логов, если что-то не так
```
Если деревень всё ещё 3, а должно 10 — мир сохранён со старой схемой. Один раз:
```bash
./manage.sh reset         # ВНИМАНИЕ: стирает текущий мир и создаёт заново (10 деревень)
```
Тонкий клиент открывается на `http://<твой-сервер>:8090/` (или как настроено).

## 2. Открыть толстый 3D-клиент (Godot)

1. Поставь **Godot 4.7+** (один исполняемый файл с godotengine.org).
2. Открой проект: `godot3d-client/project.godot`.
3. В `godot3d-client/Main.gd` вверху проверь адрес сервера (`ws://<host>:8090/ws?...`).
4. Нажми ▶ (F5). Пойдёт подключение; в правом нижнем углу — версия.

## 3. Что проверить в этой итерации (чеклист)

- **3D-деревня**: дома вдоль улиц, дороги крестом, кузница/амбар/колодец, таверна с
  вывеской и столами; вечером (18–23ч) посетители сидят ЗА СТОЛАМИ, а не кучей.
- **Комната (🛏)**: подойди к точке у таверны, пробел — снять комнату / лечь спать.
- **Тактический бой** (тонкий клиент): «🏹 Выйти на зверя» → «⚔ В бой (по раундам)».
  Проверь выбор цели (голова/корпус/руки/ноги), Защиту, Уклон, Бегство, замер удара.
  Раны дают последствия: бьющая рука ранена → слабее удар; ноги перебиты → не убежать.
- **Магия** (только если персонаж одарён — панель «✨ Плетение» появляется сама):
  Пробудить дар → Свет/Лат/Искра + ползунок «вольного плетения». В бою — кнопка «✨ Искра».
  Провал даёт откат (травма+надлом). У большинства персонажей дара нет — это норма.
- **События от решений NPC**: поживи несколько дней — в «что говорят»/«памяти деревни»
  появятся исходы ватагой, смута, починные сходы, призыв вожака. В голодных/нищих
  деревнях — метка «🗡 неспокойно на дорогах» (там в пути чаще засады и разбойники).
- **Два клиента разом**: зайди тонким и толстым одним персонажем — толстый берёт
  управление, тонкий становится живым наблюдателем (баннер сверху).
- **Телефон**: открой тонкий клиент с телефона — крупные кнопки, колонки в стопку,
  липкие вкладки, нет горизонтальной прокрутки.

## 4. Текстуры — работают уже сейчас (drop-in)

**Тонкий клиент** (спрайты-заглушки): кладёшь файл в `assets/` под нужным именем —
подхватится. Полный список имён — в `ГРАФИКА.md`. Пересобрать: `./manage.sh update`
(папка `assets/` копится в образ).

**Толстый 3D-клиент**: текстуры граней берутся из `godot3d-client/textures/<имя>.png`.
Положи PNG под этими именами — боксы деревни сразу оденутся:

| файл в `textures/` | на что ляжет |
|---|---|
| `grass.png` | трава (пол деревни летом) |
| `snow.png`  | снег (пол зимой) |
| `wood.png`  | стены домов/кузни/амбара/таверны, столы |
| `roof.png`  | крыши |

Бери **бесшовные (tileable) PNG**, 512×512 или 1024×1024. Движок натягивает их
трипланарно, так что идеальной развёртки не нужно.

## 5. 3D-модели — тоже drop-in (новое в 0.9.10)

Теперь, если положить модель в `godot3d-client/models/<имя>.glb`, она **заменит
коробку-примитив** на той же клетке. Нет файла — остаётся коробка (ничего не ломается).
**Имя файла — контракт:**

| файл в `models/` | что заменяет |
|---|---|
| `house.glb`  | жилой дом |
| `tavern.glb` | таверну |
| `forge.glb`  | кузницу |
| `barn.glb`   | амбар |
| `well.glb`   | колодец |
| `table.glb`  | стол в таверне |
| `tree.glb`   | дерево по краю деревни |

Требования к модели:
- формат **.glb** (бинарный glTF — Godot импортирует сам, просто положи файл);
- «ноль» модели (origin) — у основания, по центру; модель смотрит «лицом» к −Z;
- масштаб — примерно в 1 клетку (~2 м). Если модель окажется великовата/мала —
  скажи мне, какой файл, добавлю множитель (в коде уже есть параметр `scale`).

Персонажи (токены) пока капсулы — для них нужна привязка анимаций (ходьба/бой);
это следующий шаг, сделаю, когда будут анимированные .glb персонажей.

## 6. Где брать (один стилевой набор — чтобы деревня была цельной)

Бери **CC0** и держись ОДНОГО набора, иначе стили не склеятся.

**Низкополи-модели (.glb) — лучший путь для 3D-клиента:**
- **Kenney** — https://kenney.nl/assets — наборы «Survival Kit», «Nature Kit»,
  «Medieval Town / RPG», «Mini Dungeon». CC0. Есть прямо дома/таверны/деревья/бочки.
- **Quaternius** — https://quaternius.com/ — бесплатные низкополи-наборы, в т.ч.
  **анимированные персонажи** (пригодятся для токенов позже) и природа.
- **Poly Pizza** — https://poly.pizza/ — агрегатор бесплатных .glb; поиск
  `house`, `tavern`, `well`, `tree`, `barrel`, `sword`.

**Бесшовные текстуры (.png) и небо:**
- **ambientCG** — https://ambientcg.com/ — CC0, поиск `wood planks`, `grass`,
  `thatch roof`, `snow`, `cobblestone`. Качай 1K PNG, Albedo/Color.
- **Poly Haven** — https://polyhaven.com/textures — CC0, то же плюс HDRI для неба.

**Разнородное (фильтруй по лицензии CC0!):**
- **OpenGameArt** — https://opengameart.org/ (теги `lowpoly`, `medieval`, `slavic`)
- **itch.io** — https://itch.io/game-assets/free/tag-3d
- **Sketchfab** — https://sketchfab.com/ (фильтр Downloadable + License CC0)

## 7. Как положить и проверить (по шагам)

1. Создай папки, если их нет: `godot3d-client/textures/` и `godot3d-client/models/`.
2. Скинь туда файлы под именами из таблиц выше (например `house.glb`, `wood.png`).
3. В Godot он сам импортирует при фокусе окна (увидишь их в FileSystem слева).
4. Запусти ▶ — коробки заменятся моделями/оденутся текстурами. Версия в углу та же.
5. Для тонкого клиента (спрайты в `assets/`) — после добавления `./manage.sh update`.

Если что-то встало криво (размер/поворот/не та грань) — просто скажи, какой файл и что
не так: поправлю множитель/смещение в коде за минуту, арт при этом трогать не нужно.

### Коротко
- Код обновляется `./manage.sh update`; мир при смене схемы — `./manage.sh reset`.
- Текстуры: `assets/` (тонкий) и `godot3d-client/textures/` (толстый) — уже работают.
- Модели: `godot3d-client/models/<имя>.glb` — заменяют коробки по именам из таблицы.
- Один набор CC0 (Kenney/Quaternius для моделей, ambientCG/Poly Haven для текстур).
