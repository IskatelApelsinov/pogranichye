# 3 — Разработка

Всё, что нужно команде, чтобы доделывать игру и добавлять модули.

- `docs/`    — дизайн-документы и гайды. Начни со `СКЕЛЕТ-ЖИВОГО-МИРА.md`.
- `tools/`   — инструменты разработки (генераторы, пробники, визуализация).
- `builds/`  — записи билдов/релизов.
- `archive/` — архивы и старый Python-прототип как референс (переезжает сюда отдельным шагом).
