# 001 — Подготовить Blender для конвейера игровых ассетов

**Исполнитель:** владелец проекта.  
**Инструмент:** Blender.

## Цель

Подготовить локальную среду, чтобы позже можно было пакетно генерировать/обрабатывать визуальные ассеты для Unity. Пока ничего не моделировать и не менять в Unity.

## Шаги

1. Завершить установку Blender.
2. Запустить Blender и проверить, что он открывается без ошибок.
3. Сообщить ИИ точную версию Blender (Help → About Blender).
4. Пока не создавать и не экспортировать модели: сначала ИИ подготовит единый шаблон сцены, правила масштаба, имён, материалов, LOD/collider и экспортный скрипт под текущий URP-проект.

## Критерии готовности

Blender запускается; версия записана в этом файле после выполнения. Никакие игровые файлы не изменены.
