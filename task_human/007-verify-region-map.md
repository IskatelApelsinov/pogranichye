# 007 — Проверить карту края после typed DTO

**Исполнитель:** владелец проекта  
**Версия:** Unity 6000.6.7f1 / URP  
**Когда:** после обновления main с PR #641.

## Проверка

1. Открыть карту края в поселении.
2. Убедиться, что текущий пункт помечен «Ты», посещённые и известные поселения показывают имена, неизвестные концы дорог остаются без имени.
3. Проверить дороги: линии соединяют только серверные узлы, а список предлагает только узлы, присланные сервером.
4. Увеличить карту колёсиком/кнопкой и вернуть «Весь край».
5. Начать путешествие к известному или неизвестному узлу, если сервер его разрешает; исход и прогресс должны приходить от сервера.
6. Проверить отсутствие региона/пустой регион: клиент не должен падать и не должен достраивать карту из `/api/world`.
