# 014 — Unity acceptance: server-authored tavern window glazing

**Исполнитель:** владелец проекта  
**Версия:** Unity 6000.6.7f1 / URP  
**PR:** client integration for /api/spaces v1.35

## Проверка в Unity

1. Запустить актуальный сервер и подключиться к стартовому поселению с Layout v2.
2. Войти в корчму и убедиться, что /api/spaces содержит поверхности kind "window" с transparent=true.
3. Посмотреть на окна изнутри и снаружи при дневном освещении: стекло должно быть полупрозрачным, без непрозрачной деревянной плоскости поверх проёма.
4. Проверить ночное время и тёплое освещение корчмы: стекло не должно превращаться в чёрную непрозрачную заглушку или чрезмерно яркую плоскость.
5. Проверить, что окно остаётся физически непроходимым: игрок не должен проходить через стекло или получать новый вход в здание.
6. Проверить двери отдельно: штатный проход через серверную дверь остаётся единственным способом входа/выхода.
7. Не менять серверный collidable и не добавлять локальные проходы для исправления визуальных дефектов.
8. Приложить скриншоты изнутри/снаружи, Unity Console и F3 dump с версией кадра/чанка.

## Критерий завершения

Подтвердить фактическое дневное освещение и отсутствие прохода через окно в Play Mode. Unity-independent CI не считается визуальной или физической runtime-приёмкой.
