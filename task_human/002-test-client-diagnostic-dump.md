# 002 — Проверить сохранение диагностического дампа Unity

**Исполнитель:** владелец проекта  
**Подсистема:** Unity client / ручная проверка диагностики.  
**Связано:** `task_ai/004-chatgpt-client-diagnostic-dumps.md`.

## Что сделать

1. Обновить локальную копию репозитория до актуального `main`.
2. Открыть проект в Unity 6000.6.7f1 и дождаться компиляции.
3. Запустить сцену. Нажать F3 — должна открыться панель «Техническая диагностика».
4. Нажать «СОХРАНИТЬ ДАМП ДЛЯ ОТЛАДКИ».
5. Посмотреть путь к JSON-файлу, который появится внизу панели.
6. Повторить сохранение после входа в мир и небольшой прогулки.
7. Приложить сюда один дамп, желательно сделанный после входа в мир.

## Что сообщить

- Появилась ли ошибка компиляции (если да — полный текст Console).
- Сохраняется ли файл по указанному пути.
- Открывается ли JSON в редакторе.
- Приложить файл сюда через скрепку/перетаскивание.

## Важно о приватности

Дамп локальный и не отправляется автоматически. Он может содержать идентификаторы персонажа, координаты, NPC-имена, инвентарь и игровую ленту. Прикладывай его только если готов поделиться этими игровыми данными.

Не нужно менять код, запускать серверные команды или моделировать что-либо в Blender для этой проверки.

**Критерий выполнения:** JSON-файл сохранён, открыт и приложен к чату; ошибки/результат записаны ниже.

## Результат

Ожидает проверки владельцем проекта.
