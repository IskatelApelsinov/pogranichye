# 003 — Проверка базовой играбельности демо после клиентских исправлений

**Исполнитель:** владелец проекта  
**Подсистема:** Unity runtime acceptance.  
**Основной план:** `3-dev/docs/ПЛАН-ВОССТАНОВЛЕНИЯ-ДЕМО.md`.

## Порядок проверки

После того как ChatGPT сообщит, что конкретная итерация клиентских изменений готова к проверке:

1. Обновить main и открыть проект Unity 6000.6.7f1.
2. Проверить Console на compile errors.
3. Запустить сцену и войти в мир.
4. Проверить мышь/камеру: комфортно ли смотреть, нет ли рывков.
5. Проверить спринт: хватает ли длительности и корректно ли восстанавливается выносливость.
6. Подойти к NPC, поговорить, выбрать реплику кнопкой, выполнить одно действие/поручение.
7. Проверить взаимодействие с дверью/стойкой/POI без попадания raycast в стену.
8. Осмотреть дома: нет ли наложений, перекрытых дверей и непроходимых проходов.
9. Зайти в таверну и проверить доступность жителей и сценария пива.
10. Пройти за пределы поселения и записать, появляется ли связное окружение или снова пустая земля.
11. Нажать F3 и сохранить диагностический дамп после прогулки.

## Что приложить

- Скриншот/короткое видео при проблеме.
- F3 JSON dump после воспроизведения.
- Полный текст ошибок Unity Console.
- Коротко: шаги воспроизведения и что ожидалось/что произошло.

Не нужно самостоятельно менять код или запускать серверные команды для этой проверки.

## Критерий выполнения

Проверенные сценарии и материалы приложены к чату; задача остаётся в работе, пока все P0 сценарии не пройдены.


## Дополнение после жалоб по UX/деревне/звуку/горам — 15.11.2026

21. На HUD-карте, карте края, инвентаре и журнале есть видимые «Назад»/«Закрыть»; Escape закрывает верхнее окно и не открывает другое поверх него.
22. На расстоянии от рынка/конюшни/корчмы соответствующее торговое/служебное окно не отображается и не блокирует WASD. Навести центр экрана на серверный interaction target, нажать E — окно открывается, персонаж останавливается; кнопка закрытия и Escape закрывают его и возвращают управление.
23. Проверить на 720p/узком окне: contextual window не исчезает из-за того, что HUD раскрыт; есть доступная кнопка закрытия.
24. После получения серверного Layout v2 не остаётся `PrototypeVillage` и не появляются старые фиксированные дома/рынок/кузница/поля. При отсутствии Layout нет тестовой деревни: виден честный loading/empty state.
25. Проверить, что клиент не создаёт случайные деревья, кусты, grass tufts, yard props, barrels/crates/baskets без server decorations/scatter descriptor. Серверные building/road/zone/river/POI descriptors должны совпадать с картой и видимым миром.
26. Звук костра слышен только у серверного POI `hearth`; его источник совпадает с местом очага при смене settlement anchor. Если POI отсутствует, источник не играет у центра мира. Forge/tavern/water anchors аналогично должны совпадать с серверными descriptors.
27. Горы: проверить дальний силуэт из разных поселений; крутые склоны затрудняют подъём, отвесные скалы непроходимы, а естественные перевалы и седловины позволяют пересечь хребет. Никакого кругового или невидимого барьера. До server implementation эти пункты не считать пройденными.

Unity Editor 6000.6.7f1 + PlayMode/live-server run обязательны. Pure C# CI не заменяет эти проверки.


## Дополнение — корректная навигация POI и проходимость гор (2026-11-16)

- В TAB-панели нет «← Назад»/«× Закрыть» для контекстных мест. Проверить, что эти элементы находятся только внутри открытого по E окна корчмы/рынка/конюшни; Escape и «× Закрыть» закрывают окно и возвращают управление. «← Назад» показывается только на вложенном экране и возвращает на предыдущий экран этого же места.
- Горы не образуют абсолютную или круговую границу. Проверить нормальное движение по равнине/пологим склонам, постепенное замедление на крутых склонах, физическую непроходимость только отвесных участков и возможность пересечь хребет через естественный перевал/седловину.

## Дополнение: вложенная навигация корчмы — 2026-11-17

28. В окне корчмы проверить три уровня: «Корчма» → «Карточный стол» → «Партия». Из партии кнопка «← Назад» возвращает к выбору «Очко» / «Дурак»; ещё один «Назад» возвращает к корчме, где снова доступна покупка/употребление пива. На домашнем экране корчмы кнопки «Назад» нет — есть только «× Закрыть».
29. Escape проходит те же уровни и не закрывает всё окно преждевременно. «× Закрыть» закрывает окно с любого уровня. Закрытие/возврат не отправляет `card_game:leave` и не меняет серверную партию; активную партию можно продолжить после повторного открытия карточного стола.
30. Клавиши 1/2 начинают новую игру только на экране выбора; игровые клавиши работают только на экране активной партии. Проверить, что на главном экране корчмы случайное нажатие 1/2 не запускает ставку.
