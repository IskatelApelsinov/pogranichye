# 006 — Проверить характеристики, суму и лошадь в Unity

**Исполнитель:** владелец проекта  
**Версия:** Unity 6000.6.7f1 / URP  
**Когда:** после обновления main с consolidated PR #641.

## Проверка

1. Открыть проект и убедиться, что Console не содержит compile errors.
2. Открыть инвентарь: шесть характеристик отображаются числами из серверного кадра.
3. Проверить суму: load/capacity и предупреждение перегруза совпадают с серверным состоянием; отсутствие поля от старого v1 сервера не ломает вход.
4. При наличии лошади проверить:
   - имя, силы, принадлежность и признак `here`;
   - седельная сумка отдельно от переносимой сумы;
   - mount/dismount меняет позу/визуал только после нового серверного кадра;
   - кормление и перенос предметов отображают результат только после серверного подтверждения.
5. Без лошади UI показывает предложение покупки у конюшни только при серверном наличии лошади в `place.stable` и достаточном числе монет.
6. Пройти пешком и верхом небольшой маршрут: клиент не должен самостоятельно менять скорость/выносливость/позицию как авторитетное состояние.

## При ошибке

Приложить Unity Console stack trace и F3 diagnostic dump. Указать, какой кадр/действие привёл к ошибке.

## Ограничения

- Не менять Go сервер и протокол.
- Не считать визуал лошади доказательством её серверного существования.
- Не отмечать задачу выполненной до фактического теста.
