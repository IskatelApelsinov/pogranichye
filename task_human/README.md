# Задачи владельцу проекта

Обязательные правила: `../AI_WORK_RULES.md`.

Здесь только конкретные действия, которые должен выполнить человек: запустить Unity, проверить сборку/сцену, установить инструменты, подготовить исходные материалы, выполнить локальный Blender batch и т.п.

Статусы в первой строке:
- `!В работе`
- `!Выполнено`
- `!Блокировано`

После выполнения замени первую строку на `!Выполнено` и допиши коротко: что сделал, версия инструмента, результат/ссылка на commit. Если не получается — напиши причину, не угадывай.

ИИ не должен перекладывать на человека задачи, которые может выполнить сам. Не просить запускать Unity/Blender без конкретной инструкции и ожидаемого результата.
