# 004 — ChatGPT: диагностические дампы Unity-клиента

**Исполнитель:** ChatGPT  
**Подсистема:** Unity client / diagnostics.  
**Связано:** task_ai/003-chatgpt-typed-gameplay-state.md, 3-dev/comms/0231-chatgpt-client-diagnostic-dumps.md.

## Цель

Дать владельцу проекта возможность в любой момент сохранить компактный диагностический пакет из Unity, который можно приложить к чату ChatGPT/Claude для разбора проблем клиента и интеграции с серверной симуляцией.

Дамп описывает только наблюдения клиента. Он не становится источником истины о мире и не подменяет серверные логи.

## Уже реализовано (source-level)

- bounded ring buffers для full/fast/rejected server frames и технических событий;
- ручное сохранение JSON из F3 diagnostic overlay;
- краткий контекст Unity/platform/server/connection/place/position/AOI/terrain/movement;
- запись intent только в виде op + reqid, без полного payload;
- не записываются chat/voice envelopes, токен, пароль, логин;
- дамп содержит приватные игровые сведения (ID, координаты, NPC-имена, инвентарь и ленту событий); файл остаётся локальным и прикладывается к чату только вручную;
- ограничение размера кадра, числа записей и ротация старых файлов.

Код:
- 2-client/game/Assets/_Project/Scripts/Diagnostics/ClientDiagnosticDumps.cs
- 2-client/game/Assets/_Project/Scripts/Runtime/VerticalSliceController.cs

## Ограничения

- Не менять Go server, wire contract, authoritative simulation или intent semantics.
- Не писать полный исходящий payload, credentials, chat/voice payloads или SDP/ICE.
- Не сохранять дампы автоматически без явного действия пользователя.
- Не включать непрерывное файловое логирование на горячем пути; пока только bounded in-memory capture и ручная запись.
- Сохранять world frame как данные сервера, а не реконструировать локально.
- Любое расширение схемы — с версией pogranichye.client-dump.v1 или новой явной версией.

## Критерии завершения

- Unity compile проходит.
- Ручной dump capture работает в title/login и в активном мире.
- JSON валиден и содержит диагностически полезные full/fast/rejected кадры и контекст.
- Credentials и raw chat/voice/outbound payloads отсутствуют.
- Retention и memory bounds подтверждены.
- Путь и способ приложить файл описаны владельцу.
