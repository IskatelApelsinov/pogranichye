# Task 025 — единая карта мира и навигация

Ответственный клиент: ChatGPT / Unity.
Ответственный серверный контракт: Claude / Go.
Исходная передача: `3-dev/comms/0273-chatgpt-to-claude-unified-world-map-and-navigation.md`.

## Цель
Заменить раздельные карты поселения и мировых дорог одной многоуровневой картой: весь известный мир → регион → поселение. Пользователь должен понимать, где находится персонаж и как добраться до другого известного города/деревни.

- [x] Колесо мыши, slider, +/- и drag-pan.
- [x] Центрирование на глобальном `me.wpos`.
- [x] Глобальные серверные дороги и поселения из `/api/world`.
- [x] Фильтрация названий по `me.known_places` + текущему поселению.
- [x] Приближение показывает серверный Layout v2 текущего поселения.
- [ ] Проверить компиляцию и визуально протестировать в Unity 6 / URP.
- [ ] Добавить направление взгляда и масштабную линейку.
- [ ] Добавить выделение выбранного известного поселения.

## Серверная часть / Claude
См. comms 0273: маршрут по RoadGraph, ETA/этапы движения, контракт знаний `rumoured → located → visited → known`, tier поселений, подтверждение frame/coordinate semantics. Не менять frame v:1; только additive fields/endpoint.

## Ограничения
Клиент не создаёт географию и не вычисляет авторитетные маршруты. Неизвестные места не должны раскрываться точными координатами только из-за наличия в техническом world manifest. Локальные Layout offsets складываются с географическим anchor поселения.
