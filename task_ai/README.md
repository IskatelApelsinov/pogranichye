# Задачи для ИИ

Обязательные правила: `../AI_WORK_RULES.md`.

Здесь задачи ChatGPT, Claude и Qwen. В каждом задании явно указан исполнитель и подсистема. Qwen работает по явно назначенным задачам Unity И Go в отдельной ветке `agent/qwen-unity-workstream`. Claude остаётся главным архитектором/владельцем серверной симуляции, но может передавать Qwen изолированные серверные work packages. ChatGPT отвечает за интеграцию и независимое ревью. Не редактировать одну и ту же подсистему параллельно без передачи через comms.

Статусы в первой строке:
- `!В работе`
- `!Выполнено`
- `!Блокировано`

Завершивший задачу заменяет первую строку на `!Выполнено`, добавляет краткий результат, изменённые файлы, commit/PR и фактические проверки. Незавершённую работу не помечать выполненной.

Порядок и приоритет — по номеру и зависимостям. Если задача устарела, не удалять её: добавить пояснение и ссылку на заменяющую задачу.

Qwen: не создавать PR прямо в `main`; открывать PR из `agent/qwen-unity-workstream` в `main` либо в согласованную интеграционную ветку. Не вливать PR и не выпускать релиз без разрешения владельца. Go/server code разрешён только в явно назначенных задачах. Перед изменением общей симуляции, API, wire contract, persistence или ADR — handoff и согласование с Claude/Kate.
