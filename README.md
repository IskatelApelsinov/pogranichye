# Приграничье

Server-authoritative живой мир (isekai/попаданец): сервер симулирует мир, клиенты — окна.
Перезапущен как **живой-мир-сначала** после разбора мёртвого прототипа. Дерево:

- **1-server/** — сервер мира на Go: мозг и память (ядро, разум НПС, кости, память без потерь, экономика).
- **2-client/** — толстый клиент на Unity (C#).
- **thin-client/** — тонкий клиент: сайт + игра + свои данные (регистрация отдельна, работает в любом клиенте).
- **accounts/** — служба аккаунтов: знает пользователей, НЕ знает мир; подключает игрока к персонажу.
- **3-dev/** — разработка: дизайн-документы, инструменты, билды, архив (старый прототип — в `archive/legacy-prototype/`).

## Запуск

Через Docker (одной командой, отдаёт и сервер, и тонкий клиент):
```
docker compose up -d --build      # затем открой http://localhost:8090/
```
Или из исходников:
```
cd 1-server
go test ./...                     # все тесты
go run ./cmd/pogserver            # сервер :8090 → http://localhost:8090/ (регистрируйся, вселяйся в жителя)
go run ./cmd/pogserver -demo -days 5910   # headless-прогон с «отчётом о жизни»
```
