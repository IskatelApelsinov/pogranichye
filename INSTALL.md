# Установка и запуск на тестовой виртуалке (Debian 12 в VirtualBox)

Цель: на виртуалке (ВМ) поднять игру в Docker, а с основного компьютера (хоста)
зайти в неё в тонком (браузер) и толстом (Godot) вариантах.

Термины: **хост** — твой основной ПК; **гостевая ОС / ВМ** — Debian внутри
VirtualBox; **Docker** — система контейнеров (запускает приложение и базу в
изолированных «коробках»); **порт** — номер «двери» сети (у нас 8090).

---

## Шаг 1. Сеть ВМ: чтобы хост видел игру в ВМ

Выбери ОДИН способ (проще — A).

### A. NAT + проброс порта (работает всегда, роутер не нужен)
NAT — сеть «через хост»; по умолчанию снаружи в ВМ не зайти, поэтому пробрасываем порт.
1. Выключи ВМ. VirtualBox → выбери ВМ → **Settings → Network → Adapter 1**:
   тип **NAT**.
2. Там же **Advanced → Port Forwarding** → добавь правило:
   - Name: `game`, Protocol: `TCP`, Host IP: пусто, **Host Port: 8090**,
     Guest IP: пусто, **Guest Port: 8090**.
3. Сохрани. Теперь с хоста игра будет на `http://localhost:8090`.

### B. Bridged (ВМ получает свой адрес в твоей сети)
1. **Settings → Network → Adapter 1** → тип **Bridged Adapter**, выбери свою
   сетевую карту.
2. В ВМ узнай её адрес: `ip a` (ищи строку `inet 192.168.x.x`).
3. С хоста игра будет на `http://192.168.x.x:8090` (этот адрес вместо localhost).

---

## Шаг 2. Поставить Docker в ВМ (один раз)

В терминале Debian:
```bash
sudo apt update
curl -fsSL https://get.docker.com | sudo sh        # официальный установщик Docker
sudo usermod -aG docker $USER                      # чтобы docker работал без sudo
# выйди из сессии и зайди снова (или: newgrp docker), чтобы группа применилась
docker --version && docker compose version          # проверка
```
Если нет `curl`: `sudo apt install -y curl`.

---

## Шаг 3. Положить проект в ВМ

Код — в архиве `pogranichye.tar.gz` (пришлю в чат). Перенеси его в ВМ любым способом:
- **Общая папка VirtualBox** (Shared Folders), или
- флешка, или
- `scp` (копирование по сети), если в ВМ включён SSH.

В ВМ распакуй:
```bash
mkdir -p ~/pogranichye && tar -xzf pogranichye.tar.gz -C ~/pogranichye
cd ~/pogranichye
```

(Позже, когда подключим GitHub, этот шаг заменится на `git clone <репозиторий>`.)

---

## Шаг 4. Запустить игру в Docker

Для теста запускаем в dev-режиме (**работает вход гостем**, без регистрации):
```bash
GAME_ENV=dev DB_PASSWORD='придумай-пароль' docker compose up -d --build
```
Первый запуск соберёт образ и поднимет PostgreSQL — пару минут. Проверка:
```bash
curl http://localhost:8090/healthz        # должно вернуть {"ok": true}
docker compose ps                         # оба сервиса (app, db) — up
docker compose logs -f app                # логи сервера (Ctrl+C выйти)
```
Остановить: `docker compose down` (данные БД сохранятся в томе `pgdata`).
Перезапуск после правок кода: `docker compose up -d --build`.

---

## Шаг 5. Зайти с хоста — ТОНКИЙ клиент (браузер)

На основном компьютере открой браузер:
- способ A (NAT): `http://localhost:8090`
- способ B (bridged): `http://192.168.x.x:8090` (адрес из шага 1B)

Нажми **«Играть гостем (тест)»** — и ты в мире. Это и есть тонкий клиент.

---

## Шаг 6. Зайти с хоста — ТОЛСТЫЙ клиент (Godot)

1. На хосте поставь **Godot 4.3+** (бесплатно, godotengine.org — один исполняемый файл,
   установка не требуется).
2. Открой Godot → **Import** → выбери папку `godot-client` из проекта → **Open**.
3. Укажи адрес сервера: в дереве сцены выбери узел **Main** → в Инспекторе справа
   поля **Host** и **Port**:
   - способ A (NAT): Host `127.0.0.1`, Port `8090`
   - способ B (bridged): Host `192.168.x.x`, Port `8090`
4. Запусти (**F5**). Клиент войдёт гостем, покажет изо-сцену деревни и кнопки
   действий. Это толстый клиент на том же сервере.

> Важно: сервер уже слушает на всех адресах (в контейнере `GAME_HOST=0.0.0.0`),
> так что и браузер, и Godot подключаются одинаково — отличается только адрес хоста.

## Если что-то не так
- `curl localhost:8090/healthz` в самой ВМ не отвечает → смотри `docker compose logs app`.
- С хоста не открывается, а в ВМ работает → это сеть (шаг 1): проверь проброс порта
  (A) или адрес ВМ и что порт 8090 не закрыт фаерволом (B).
- Порт 8090 занят → поменяй внешний порт: `APP_PORT=9090 docker compose up -d`
  (тогда заходи на `:9090`; в Godot тоже ставь 9090).
- Боевой режим (без гостя, только аккаунты): убери `GAME_ENV=dev` (по умолчанию `prod`).
  За публичным доступом добавь TLS-прокси и `GAME_SECURE=1` (см. `SECURITY.md`).
