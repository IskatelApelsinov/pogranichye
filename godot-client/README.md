# Прототип клиента на Godot 4

Толстый ПК-клиент поверх того же сервера, что и браузер. Логика — на сервере;
клиент рисует состояние и шлёт намерения по WebSocket.

## Запуск
1. Поднять игровой сервер в **dev-режиме** (чтобы работал гостевой вход):
   ```bash
   cd ..            # папка stage1
   GAME_STORAGE=sqlite python3 netserver.py
   ```
2. Открыть Godot **4.3+** → Import → выбрать папку `godot-client` → Run (F5).
3. Клиент войдёт гостем, откроет WebSocket и покажет состояние. Кнопки:
   работать (дрова), охота (с авто-ударом), выпить, в путь к соседу, сохранить.

Адрес сервера — в свойствах узла `Main` (host/port), по умолчанию 127.0.0.1:8090.

## Что рисует прототип
- **Изометрическая сцена** деревни (`World2D.gd`), нарисованная примитивами: ромб-тайлы
  земли, кубики-строения, токены-жители и ты (⭐). Зимой земля белеет.
- **Движение по времени суток**: днём жители по делам, вечером — в таверну, ночью —
  по домам (спят, «zzz»), с затемнением и горящими окнами. Токены плавно едут к цели.
- Кнопки намерений: работа, охота, выпить, **в кровать (сон)**, в путь к соседу.

## Что доказывает прототип
- Сервер клиент-агностичен: тот же протокол, что у браузера и у `client_cli.py`.
- Приём пуша состояния и **дельт**, отправка намерений — всё в `Main.gd`.
- Каркас 2.5D под наращивание: заменить примитивы на спрайты-арты, добавить карту
  региона и анимацию каравана. Контракт протокола — в `../ТОЛСТЫЙ_КЛИЕНТ.md`.

Это тестовый каркас (UI/сцена строятся кодом), не финальный вид.
