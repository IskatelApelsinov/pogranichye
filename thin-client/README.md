# Тонкий клиент — сайт + игра + свои данные

Отдельная часть дерева (по замыслу Kate): веб-клиент со своим сайтом, игрой и данными.
Регистрация отдельна от мира и работает в любом клиенте; войдя, игрок вселяется в жителя
живого мира и управляет им. Протокол — websocket/JSON (тот же, что будет у Unity).

- `web/index.html` — мобильный веб-клиент: вход/регистрация → вселение в персонажа →
  состояние (здоровье/сытость/силы/настрой), деревня, соседи, кнопки целей (работать/есть/
  отдыхать/в таверну). Авто-обновление раз в секунду по websocket.

Запуск (сервер отдаёт этот клиент): из `1-server/` →
`go run ./cmd/pogserver -web ../thin-client/web`, затем открой http://localhost:8090/
