# Мега-итерация: план и бэклог (копим идеи, реализуем по циклу идея→реализация→тест)

Статус: **ПЛАНИРОВАНИЕ**. Ничего из этого ещё не реализовано. Собираем сюда всё, что
войдёт в большую итерацию ближе к концу недели (по слову Kate). Версионирование: до
релиза держимся в `0.x`, дробим мелко; **`v1.0` = первый публичный релиз на сервере**
(нормальные текстуры, геймплей, стабильность, прод-развёртывание по ПРОД-ИНТЕГРАЦИЯ.md).

Принцип работы: **идея → реализация → тест**, по кругу; большие куски собираем слоями,
каждый слой с тестами, чтобы при затягивании одного другое уже играбельно.

---

## A. 3D-клиент: из «поля 3×3» в настоящее место
- Деревня как место: площадь, дома вдоль улиц, колодец/рынок, окраина с полями/лесом;
  раскладка из серверных данных (число домов = население; таверна/кузница/амбар — из состояния).
- **Входимые здания**: таверна с интерьером — столы, за которыми сидят NPC/игроки
  (наш `tavern_tonight`), стойка корчмаря, комнаты под аренду (rent/owned → конкретная дверь).
- **Дороги для путешествий** между деревнями; по ним едет караван, случаются дорожные события.
- **Камера для тестов**: ортокамера (сейчас) → вид со спины (follow) → от 1-го лица.
  Делается камерой + слоем ввода; боевую математику не трогает (см. принцип «ввод отдельно от расчёта»).
- 3D — только витрина поверх готового сервера; логику не переписываем.

## B. Боевка
- Две скорости: тело игрока быстро + предсказание на клиенте; мир подтверждает неспешно.
  Против NPC/зверья (не синхронный PvP) — дёшево и достижимо.
- **Изометрика сначала** (клик-таргет + уклонение/парир), от 1-го лица позже.
- **Ввод отделён от расчёта**: combat принимает «удар туда с такой точностью»; откуда он
  (мышь/рука) решает тонкий слой ввода → переход на FP не трогает урон.
- **Боевка орудием**: у оружия тип/дальность/скорость/урон (инвентарь-оружие уже есть).
- **Хитпоинты + части тела** (канон, гибрид): у части свой запас + общий, удар даёт системный
  эффект — это слой ТОЛСТОГО клиента; тонкий резолвит как бросок кости против состояния.
- Исход решают: присутствует игрок → его скилл; отсутствует/фон (шальная стрела) → кости
  (ядро `world/dice.py` уже готово).

## C. Магия (плетения)
- Магия **только для магов**: гейт за предрасположенностью (бросок при рождении) + навыком;
  у большинства NPC её нет.
- Первый ломоть: 2–3 простых плетения (искра/свет/лечение) как комбо известных схем +
  свободное плетение — **азарт** (получится/нет) через кости + веса. Мана — «чем действуешь».
- Провал уводит в опасность (откат/травма) — тоже бросок. Плетение видят только опытные маги.

## D. События от решений NPC
- Каждое крупное событие (война/миграция/нехватка) — от решения NPC-носителя; порог двигают
  метрики, замаскированные под настроение (перенаселение → раздражительность → ниже порог).
  Вешается на A-life (social/ambition/dwelling) + экономику.
- Игрок качает вероятности, не диктует исход — тот же язык весов, что у мира (на костях+весах).

## E. Психика
- Новая ось (стресс/душевное состояние сверх «настроя»): растёт от увиденной смерти, отката
  плетения; мешает колдовать и трезво решать (бросок на панику). Игровая фикция, не психиатрия.

## F. A-life и логика мира — доделка
- У каждого NPC цель (utility AI + когнитивный LoD); отношения, фракции.
- Распространение репутации «со скоростью гонца» (через торговцев/почту) — канон.
- Плотность связей в экономике (дровосек→уголь→кузнец→инструмент→износ) — живость через сцепку.

## G. Расширение мира → материк
- Шардинг/LoD уже для этого (10 деревень → сотни; холодные считаются даром). Нужен worldgen
  материка (регионы-контейнеры), карта мира, биомы.
- **Больше имён и топонимов**: расширить генераторы имён + генератор названий мест
  (приставка+корень+суффикс по биому/региону).
- **Данжи**: отдельный тип локации, доходишь путешествием; лут = «погребённое наследие» (канон).
- **Дикие зоны высокой магии на границе**: плотность монстров + магические аномалии, риск/добыча.
- Типы локаций: деревня / город / данж / дикая зона.

## H. Тонкий клиент — доделка параллельно
- Оптимизация ОТДЕЛЬНО под смартфон и под браузер: тач-first (крупные цели, без hover),
  меньше анимаций/токенов на телефоне, лёгкий путь рендера; PWA уже есть.
- Единый источник правды: тонкий и толстый делят ОДИН персонаж/сервер — иначе доделка разъедется.

## I. Одновременный вход в оба клиента — «лестница присутствия»
Опасности данных нет (намерения сериализуются под замком). Это ПРАВИЛО, не баг:
- Уровни: **AI (офлайн) < тонкий (рутина, кости) < толстый (воплощение, реальное время)**.
- Сервер на персонажа держит «место души» (controller = connection_id + уровень). Управляет
  самый высокий из подключённых; остальные — **наблюдатели своего же персонажа** (живой read-only).
- Толстый поверх тонкого → «душа входит в тело», тонкий = живой зритель; закрыл толстый →
  контроль падает на тонкий, закрыл всё → на AI (экстренное воплощение из канона).
- Два одинаковых уровня на одно тело → перехват (новый забирает, старому «управляют в другом
  клиенте») либо отказ; перехват мягче при пересадке thin→thick.
- Намерения наблюдателя сервер игнорирует (кроме чата). При разрыве контроллера — отсрочка
  (`OFFLINE_AFTER`), потом контроль ниже по лестнице.
- Бонус для тестов: толстый (действие) + тонкий (панель) одного персонажа на двух экранах.

## J. Мои добавки (поддержаны Kate)
- **Реплеи/запись сессии** на детерминированной основе (seed+события → воспроизвести баг/бой).
- **Диегетичность насквозь** — ни один индикатор не торчит; всё через речь мира.
- **Хроника как контент** (песни барда, надгробия, доска объявлений) — симуляция читается как история.
- **Звук/атмосфера** (гул таверны, погода) — дешёвый буст погружения.
- **Инструменты теста**: `/observe` + «пихалка» (вызвать событие/погоду/монстра руками).
- **Процедурный пролог** из живого мира (бандиты рядом → бандитский пролог).
- **Перф-тумблеры** (лок FPS 15/30/60) — канон, не забыть.

## Предлагаемый порядок внутри итерации (слоями, каждый с тестом)
1. 3D-деревня + входимая таверна (столы/аренда) + дороги — витрина поверх сервера.
2. Боевка против зверья/бандитов (iso, клик-таргет, уклонение) на костях/скилле.
3. Магия: 2–3 плетения + свободное плетение-азарт; гейт «только маги».
4. События от решений NPC на порогах-весах.
5. Правило одновременного входа (лестница присутствия) — закладываем вместе со слоем 1.
6. Модели/текстуры из ОДНОГО набора — параллельно слою 1 (заменяют примитивы по именам узлов).
7. Тонкий клиент: мобильная оптимизация — параллельно, отдельной веткой.

## Текстуры/модели (коротко; полную инструкцию по скачиванию соберу в конце)
Godot ест .glb/.gltf (модели с анимацией) и PNG/JPG (текстуры) — файл в проект, движок
импортирует сам. Брать ОДИН стилевой набор, чтобы деревня была цельной:
- **Kenney.nl** — низкополи-киты (Survival/Nature/Castle/Medieval Town/Mini Dungeon), CC0.
- **Quaternius** — бесплатные анимированные низкополи-персонажи и природа.
- **Poly Pizza** — агрегатор бесплатных .glb (поиск tavern/house/sword).
- **ambientCG / Poly Haven** — бесшовные CC0-текстуры и HDRI.
- **OpenGameArt / itch.io / Sketchfab (CC0)** — разнородно, фильтровать по лицензии.
