# Тонкий клиент на смартфонах — план

Тонкий клиент — это веб-страница поверх WebSocket, значит он УЖЕ работает в любом
мобильном браузере. Нужен не новый клиент, а правильная «упаковка» и каналы.

## Рекомендация (по порядку, от дешёвого к охватному)

### 1. PWA — сделано ✓
Тот же веб-клиент ставится на телефон «как приложение» (иконка, полный экран, без
адресной строки). Добавлены `manifest.webmanifest`, `sw.js`, иконка, мета-теги.
Плюсы: ноль доп-кода на платформу, работает на iOS/Android, обновляется мгновенно.
Этого достаточно для беты на телефонах.

### 2. Telegram Mini App — лучший канал для RU-аудитории (следующий шаг)
Telegram открывает наш же веб-клиент во встроенном webview. Что это даёт:
- **Вход без пароля**: Telegram передаёт подписанный `initData` (id пользователя).
  На сервере проверяем подпись секретом бота → это и есть аккаунт (TG = личность).
  Ляжет в наш слой аккаунтов рядом с email-входом (новый способ `auth`).
- **Распространение**: запуск по ссылке/кнопке бота, никаких сторов и установок.
- **Уведомления через бота**: «на тебя напали в пути», «наследник принял двор»,
  «зима пришла» — бот шлёт пуши, возвращая игроков (у нас события уже есть).
- **Платежи** Telegram Stars/Payments — если захочется монетизацию, встроено.
Объём работы: небольшой — подключить Telegram WebApp SDK в страницу, добавить на
сервере проверку `initData` и способ входа `tg`, завести бота-лаунчер.

### 3. Нативная обёртка (стор) — только если понадобится
Capacitor/Tauri завернут тот же веб-клиент в приложение для App Store/Google Play.
Нужно лишь ради витрин сторов; PWA + Telegram покрывают основное.

## Что уже учтено для мобильных
- Адаптивная вёрстка (колонки схлопываются в одну на узком экране), `viewport-fit=cover`.
- Кнопочный ввод (тач-дружелюбно), WebSocket держит сессию при сворачивании.
- Дельта-протокол бережёт мобильный трафик (статика шлётся один раз).

## На будущее (мобайл-специфика)
- Крупнее тач-цели и панель действий снизу под большой палец.
- Вибро-отклик на попадание в мини-игре (vibration API).
- Экономия батареи: реже пуши, когда вкладка в фоне.
